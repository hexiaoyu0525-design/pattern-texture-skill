# 实录样例：从"一句话"到出图

> 用途：给"接单分流 + 逐步推荐"一条可照抄的完整样例。理论都在别的文件里，这里只展示**实际怎么说、怎么给、怎么落成提示词**。
> 场景：用户只说了一句"我想要个敦煌感的纹样"，没有风格名、没有载体、没有参考图。
> 说明：本例是流程示范，不是某次真实出图的复刻；提示词结构与 `prompt-scenes.md` 场景五一致，可直接改用。

## 目录

- 1. 开场：先翻译，再给建议（不提问）
- 2. 快速卡路线（用户想先看几个方向）
- 3. 逐步路线（用户想一站一站定）
- 4. 落成线稿提示词（可直接抄）
- 5. 线稿验收：三层闭合 + 4×4
- 6. 上色提示词（结构锁定写法）
- 7. 翻车与纠正（本例真实会遇到的两处）
- 8. 这一单最后交付了什么

## 1. 开场：先翻译，再给建议（不提问）

**用户**：我想要个敦煌感的纹样。

**我**（复述 + 翻译 + 给建议，不问"你要什么风格"）：

> 你说敦煌，我按"重彩密铺一路"理解——矿物色（土红、石青、石绿、暖金）＋ 缠枝或团花 ＋ 满铺，而不是清雅留白那一路。敦煌纹样最典型的骨架就是卷草，所以往下我按"缠枝莲"推。要是你其实想要那种大面积留白的文人感，说一声我换。

**为什么不问他**：他给的是一个感觉词，不是参数。"敦煌"这三个字已经够推出矿物色 + 卷草 + 密铺——这是 `design-workflow.md` 对话版“大方向→参数”表的用法。

## 2. 快速卡路线（用户想先看几个方向）

他如果说"先给我几个方向看看"，就出三张卡，**差别落在骨格与密度上**（不是换颜色）：

```
① 【推荐】缠枝莲 · 中密 · 矿物色
   画面：S 形卷草为骨架，莲花沿波线错位，单位含一花两叶一苞，四边可拼
   依据：缠枝是"连续"最主流的骨格，敦煌织物最常见的组合，密而不堵
   代价：必须给单元与重复向量，建议先出线稿，否则接缝半截断

② 团花 · 疏朗 · 矿物色
   画面：一朵宝相花居中，四周三枝折枝环绕，留白约四成
   依据：团花＋折枝的组合在敦煌壁画与织物里都常见，单幅读得清
   代价：结构简单，可跳过线稿；但它不铺满，做不了连续布料

③ 联珠几何 · 秩序 · 双色＋金
   画面：联珠圆点阵叠菱格，两色，边缘硬，无渐变
   依据：联珠是外来骨格本土化的典型，异域秩序感最强
   代价：极简易单调，全靠密度与配色撑
```

三张卡的共同点：母题都在敦煌体系内，变的是**骨格（缠枝 / 团花 / 几何格）**与**密度（中密 / 疏朗 / 秩序）**——这才是三张不同的设计，而不是同一张图换个色。

**用户**：就①。

## 3. 逐步路线（用户想一站一站定）

如果他说"一步一步来"，改成七站建议，**每站一句陈述式结论**，不问"这样可以吗"：

| 站 | 我给的建议 | 一句依据 |
|---|---|---|
| S1 方向 | 敦煌＝重彩密铺一路（不是文人留白） | 东方演化主线二：外来融合，植物连续纹在此成熟 |
| S2 风格 | 敦煌织物一路：满铺、强色差、卷草主导 | 密铺 + 矿物色是该路的形式语法 |
| S3 母题与骨格 | 母题＝莲（配叶与苞）；骨格＝缠枝；组织＝四方连续 | 骨格决定秩序，母题只是内容 |
| S4 线型 | 铁线描均匀线；主纹粗、配属中、地纹细 | 线型定气质；三级线宽才有层次 |
| S5 配色 | 浅米底 + 土红主 + 石青辅 + 暖金点缀，约 6:3:1 | 面积小纯度高；主色要成片（空间混合） |
| S6 成像 | 数码印花平涂 | 多色、要细节与连续，网版色数不够 |
| S7 出图 | 先线稿（要拼缝）→ 验收 → 上色 | 线稿的价值是少返工，不是审批 |

每站收尾一句："我按这个走：缠枝莲 / 四方连续 / 铁线描三层 / 浅米底矿物色 / 数码印花。下一步是线稿提示词，不改就往下。"

## 4. 落成线稿提示词（可直接抄）

```
四方连续纹样线稿，缠枝莲花母题：以 S 形卷草波线为骨架，莲花沿波线错位
排列（错位量为半个单位），单位内含一朵盛开的莲花、两片叶、一处花苞；
纯黑白线描，无灰阶无网点无渐变；铁线描，线条均匀无顿挫；
主纹线较粗、配属元素线中等、地纹线最细；线条闭合完整、首尾相接、
无断线、无开口轮廓；画面满铺、无大面积留白，四边元素均已跨边、
可无缝拼接；平视正投影，无透视、无阴影、无立体厚度；背景纯白。
```

负面词：

```
灰阶, 灰色调, 半调网点, 渐变, 断线, 开口轮廓, 未闭合线条, 线条粗细单一,
立体阴影, 透视变形, 随机排布, 骨架不一致, 接缝处半截图案, 中文字符, 水印
```

## 5. 线稿验收：三层闭合 + 4×4

| 层 | 看什么 | 本例的通过标准 |
|---|---|---|
| **线条层** | 断口、看似连上的细缝、未收口开口线 | 每一笔首尾相接；放大到 200% 无灰缝 |
| **单位层** | 单元是否完整、是否只有一个视觉中心 | 一花两叶一苞，花占单位 1/3–1/2 |
| **接缝层** | 四边元素是否跨边、拼起来对不对 | 4×4 拼接后看不出缝，无半截图案 |

任一不过就回提示词改，不要带着断线去上色——**断线会漏填，颜色漫出边界**，这是最贵的返工。

## 6. 上色提示词（结构锁定写法）

```
以这张线稿为基础精细上色：严格保留原有构图、单元位置与线条关系，
不改变任何线稿结构和线型位置，不新增元素，不减少元素；
敦煌矿物色系，土红、石青、石绿、暖金，底色浅米；
平涂为主、局部薄层次，不画明暗体积、不加高光阴影；
主色成片出现，纯色集中、不碎不散；四边保持可无缝拼接；
平面正投影，无透视、无立体、无布纹。
```

负面词在上一条基础上加：

```
新增元素, 元素缺失, 结构位移, 明暗塑造, 立体高光, 体积感, 布纹肌理, 渐变过渡
```

## 7. 翻车与纠正（本例真实会遇到的两处）

**翻车一：说出来的是"四方连续"，出图是"满屏随机花"。**
原因不是模型不听话，是**没给单元**——只写了"缠枝、四方连续"，等于给了秩序名没给内容。修法是在提示词里把单位内容写死（一花两叶一苞）并给错位量。

**翻车二：4×4 拼起来有一道明显的竖向半截花。**
原因是四边元素没跨边，接缝处把图案切断了。修法：补"四边元素均已跨边""接缝处不允许出现半截图案"，重出后再拼一次；仍不过就走 `composition-structure.md` 2.6 的斜向错接补救。

## 8. 这一单最后交付了什么

1. **定稿线稿**（母版，后续所有派生都从它走）
2. **上色彩图**（结构锁定的那张）
3. 参数包：`缠枝 / 错位半个 / 铁线描 / 四方连续 / 浅米底 + 土红石青暖金 6:3:1 / 数码印花`
4. （可选）只有用户要看展示时才做：丝巾整幅、抱枕单元级、或 7 秒成品视频

**注意第 4 项**：载体是展示手段，用户没提就不做。这一单的"成品"就是纹样本身。

> 用法：这份样例可直接当模板改——把"敦煌 / 缠枝莲"换成用户要的，其余结构（翻译 → 建议 → 线稿 → 验收 → 上色）不动。
