# 纹样成品展示视频（showcase-video）

> 用途：把定稿纹样或已落地成品做成 5–10 秒展示短片，讲清"线稿成纹 → 材质生长 → 舒展 → 陈列定格"这一条视觉主线。
> 边界：**只做成品展示**——单品静物、无人台、局部手模、成衣局部、纹样本身。**不含人物、不做剧情/走秀/品牌片**；人物出镜、秀场、TVC 归 `fashion-studio` 的 `video-brief.md` 与 `doubao-creative-video`。
> 前提：有定稿图（第 1 步上色稿，或 `product-prompts.md` 的载体落地图）。

## 适用与不适用

| 适合 | 不适合（转交） |
|---|---|
| 纹样从线到实物的"生长"过程 | 模特穿着走秀、街拍、品牌 TVC → `fashion-studio` |
| 单品静物展示（丝巾、抱枕、包袋、礼盒、云肩、首饰） | 有人物出镜的佩戴片 → `fashion-studio` |
| 成衣局部/面料特写的氛围片 | 剧情、对白、多场景叙事 → `doubao-creative-video` |
| 电商详情页与提案里的 5–10 秒动态图 | 长视频（>15 秒）多镜成片 |

## 四段结构与时长换算

四段是这条广告质地短片最稳的骨架，**删任何一段都会退化成"素材在飘"**。

| 段落 | 占比 | 做什么 | 必写要素 |
|---|---|---|---|
| 一、起手 | 0–25% | 从环境推进到主体局部，纹样被"勾"出来 | 开场环境、推进落点、线条游走路径、通感比喻 |
| 二、材质生长 | 25–55% | 光扫过，**一侧先转化、一侧仍原状** | 光的方向、率先显影区、滞后区、材质细节 |
| 三、舒展 | 55–78% | 全部转成真实材质，一次翻卷/展开 | 外力、运镜、表面高光流动、材质三特征 |
| 四、定格 | 78–100% | 落到陈列位，稳定收束 | 场景、承托物件、落位点、成型动作、定格时长 |

**时长换算**（只改时间点，不改结构）：

| 时长 | 一 | 二 | 三 | 四 | 其中定格 |
|---|---|---|---|---|---|
| 5 秒 | 0–1.25s | 1.25–2.75s | 2.75–3.9s | 3.9–4.5s | 0.5s |
| 7 秒 | 0–1.75s | 1.75–3.85s | 3.85–5.46s | 5.46–6.3s | 0.7s |
| 10 秒 | 0–2.5s | 2.5–5.5s | 5.5–7.8s | 7.8–9s | 1s |

> 低于 5 秒时第二段会被压到看不清，**保底建议 6 秒**。

## 两种开场变体（选错必失败）

### 变体 A：线稿起手（有"线稿 → 上色"过程时用）

**输入必须是定稿线稿**：过了「三层闭合」（线条 / 单位 / 接缝）验收、单色、无断线的版本。用中间稿或草稿做首帧，第一段"线条游走"会直接把开口线、断口放大给观众看，而且没法修——重跑要从线稿重来。

适用：丝巾这类先有线稿、再上色的主题。第一段写"一道线条沿主体与纹样边缘连续游走，纹样逐步被勾勒出来"，第二段做"线稿 → 材质"的转化。

完整模板（可直接填空）：

```
[时长]秒[主题类型]成品展示动画，整体呈现[广告质感定位]质感，
以"线稿成纹—材质生长—舒展—陈列定格"为视觉主线，
保持原有主体、辅助纹样、边框与配色结构稳定，不改变纹样造型。

0–25%，画面从[开场环境]进入，镜头快速推进至[主体]局部，一道[线条色]线条沿[具体部位]连续游走，
像[通感比喻]一样向四周延展，完整纹样逐步被勾勒出来；

25%–55%，进入核心转化，一道[光型]从[方向]斜向滑过，镜头贴近并横向跟随，
光经过的位置立即从线稿转化为[材质]，[率先显影区]先出现[底色]与纹样，
并生成[材质细节]，[滞后区]仍保持[滞后状态]，形成清晰的"线稿→实物"生长对比；

55%–78%，光完全扫过，全部转化为真实材质，[成品]被[外力]产生一次有力量但优雅的翻卷与舒展，
镜头[运镜]，表面高光沿褶皱连续流动；

78%–100%，镜头转入[场景]空间，[承托物件]位于画面中央，[成品]收束后落至[落位点]，
[成型动作]，镜头轻微推近并稳定收束，最后[定格时长]定格，保留柔和高光与克制的微光收束。

整体运镜节奏前快、中段清晰、后段舒缓，转场连续无硬切；
突出[风格]的[视觉关键词]；避免[负面词]。
```

### 变体 B：实物起手（只有成品图、没有线稿时用）

**这是最容易翻车的分支**：手上只有成品图（比如一张抱枕静物图），却照抄"金线勾纹"，模型会凭空造出一张不存在的线稿，或者干脆把图重绘。

改法：把第二段的"线稿→材质"换成**材质状态变化**，其余三段不动。

| 段落 | 变体 B 写法 |
|---|---|
| 一 | 从环境中推进到成品局部微距（不写"勾纹"），只写"镜头贴近表面，纹样细节逐渐清晰" |
| 二 | 一道光扫过，**已过光区**从[哑光/平面]变为[光泽/起皱/浮现纹理]，未过光区保持原状 |
| 三 | 成品被气流托起/自然摊开，一次舒展 |
| 四 | 落到陈列位定格 |

```
二段替换句：一道[光型]从[方向]扫过，光经过的区域表面由[初始状态：哑光/平整]转为[目标状态：柔亮光泽/自然起皱/凸起纹理]，
未扫过区域保持原状，形成"半明半暗"的质感生长对比。
```

> 判断口诀：**手上有线稿 → 变体 A；只有成品图 → 变体 B**。没有线稿就别写"勾纹"。

## 材质族（可替换变量）

"材质生长"的对象决定这条片的观感，按载体选一族：

| 材质族 | 生长时的表现关键词 | 典型载体 |
|---|---|---|
| 真丝 | 细腻光泽、自然起伏褶皱、精致包边 | 丝巾、方巾 |
| 棉麻/帆布 | 颗粒织纹、微皱、哑光 | 抱枕、托特包 |
| 羊毛/羊绒 | 绒面漫反射、柔软堆叠感 | 围巾、毛毯 |
| 皮革 | 细纹粒面、边缘压线、柔韧折痕 | 手提包、腰带 |
| 金属箔/烫金 | 反光跳跃、局部高光扫过 | 礼盒、纹样烫金件 |
| 陶瓷/珐琅 | 釉面高光、边缘勾金 | 胸针、摆件 |
| 亚克力/滴胶 | 通透折射、边缘透光 | 冰箱贴、饰品 |
| 刺绣/盘金 | 线迹起伏、金线断续反光 | 云肩、织物饰品 |

## 三条硬约束（缺一条就会散）

1. **结构稳定句**：`保持原有主体、辅助纹样、边框与配色结构稳定，不改变纹样造型`——不写这句，视频模型会顺手"优化"纹样。
2. **单侧先转化**：材质生长必须写"一侧已变、一侧未变"。只写"逐渐变成丝绸"会一次性全变，过程感消失。
3. **末尾定格**：最后 10% 必须稳定定格。不留定格，结尾会飘、会被截断。

## 图生视频锚点链

1. **关键帧 = 定稿图**：用第 1 步上色稿或 `product-prompts.md` 的落地图作为首帧，不要用中间草稿。
2. **一镜一生成**：正/侧/细节三个视角分别生成再拼，不要用一段文生视频硬凑多镜。
3. **首尾帧可控时**：起手帧用定稿图，定格帧用同一张或对齐变体，可显著降低漂移。
4. **纹样一致性天然弱于图片**：重要商用交付以静态图为准，视频只承担氛围与动态呈现。

## 负面提示词

**中文**：纹样变形、图案重绘、主体结构变化、边框错位、夸张布料抖动、低质塑料光、过度发光、粒子爆炸、科幻光束、频闪、鬼影、穿模、主体漂移、背景跳变、硬切、出现人物。

**English**：`pattern distortion, redrawn pattern, structure changing, border misaligned, exaggerated fabric flapping, cheap plastic light, over-glow, particles, sci-fi beams, flicker, ghosting, clipping, subject drift, background jump cut, human figure`

> 负面词不宜堆太多，8–12 个足够；过多会削弱正向描述权重。

## 平台口径

- 默认：即梦 **Seedance 2.5** 图生视频；关键帧用 **Seedream 5.5** 生成。
- 参数（时长、比例、运动强度）以平台官方为准；本文件只定结构与文案，不定平台硬参数。
- 换平台时，方法与文案不变，只换时长上限与运动幅度口径。

## 实测状态

- 【已出图实测】丝巾链路：7 秒四段结构 + 真丝材质族 + 无人台定格，完整跑通；结构稳定句与"单侧先转化"确有稳定效果。
- 【未实跑】变体 B（实物起手）、棉麻/皮革/珐琅/亚克力等材质族、云肩与首饰的展示镜头：按结构推导，尚未逐类实际生成。首次用按**画面效果**调整镜头幅度与材质词即可。
- 【平台参数】时长上限、运动强度随平台版本变化，以官方为准，不把平台参数写成技能内的固定值。
