# 产品与服饰品呈现提示词（product-prompts）

> 用途：把**已定稿的纹样**落到实物上的出图提示词——场景六（产品静物，非服装载体）、场景七（服饰品载体）。编号接续 `prompt-scenes.md` 的场景一至五，**不改动原编号**。
> 前提：纹样已在平面上定稿，并过了构成/配色/工艺自检。
> 载体适配规则（怎么改纹样、降到哪一级）见 `carrier-guide.md`；本文件只管"怎么写提示词"。
> **边界：不出现人物。** 服饰品一律无人台、局部手模、平铺、悬挂、微距；有人物穿着佩戴的画面归 `fashion-studio`。

## 与场景一至五的五点差异

1. **主体换位**：主体从"纹样"变成"物件"。顺序改为「物件 + 材质 → 纹样内容与位置 → 展示方式/构图 → 光与背景 → 质量词」，纹样退为物件上的装饰。
2. **必须写纹样位置**：中心 / 边框 / 满铺 / 单侧 / 单元定位。不写位置，模型会随机贴，十次十个样。
3. **必须写防漂移句**：`纹样完整不变形、图案不重绘`。这是把定稿纹样搬到实物上唯一有效的锚点。
4. **不写"文字完整无损"**：画面里没有品牌字时，这句会让模型硬造文字。
5. **一律声明无人物**：写 `无人台、无模特、无手部人物`；需要局部手模时写 `仅局部手模，无面部`。

## 场景六：产品静物（非服装载体）

### 6A 平面软载体（丝巾 / 抱枕 / 桌旗）

**用途**：看纹样平铺在软载体上的整体构图与材质感，用于电商主图、作品集、客户提案。

**提示词模板**：

```
[载体：真丝方巾 90×90 / 棉麻抱枕 50×50 / 亚麻桌旗]，平铺俯拍，正面完整展示，
[底色与配色方案：主色+辅助色+点缀色]，
[纹样内容：中心主纹+四角角花+外框 / 满铺折枝花卉]，纹样位置与比例准确，
纹样完整不变形、图案不重绘，
[形态细节：自然垂坠微折角 / 平挺无褶皱 / 四周精致包边与缝线]，
[背景：浅灰无缝背景 / 原木台面 / 干净墙面]，柔和均匀光，真实材质纹理与自然阴影，
商业静物摄影质感，[质量词：中高细节、清晰]
```

**负面词**：见下方「产品静物」组。

**参数**：1:1；风格强度低；细节强度中高（要看清纹样，不要艺术发挥）。

---

### 6B 立体硬载体（礼盒 / 包装 / 冰箱贴 / 亚克力牌）

**用途**：看纹样在多面体或小件硬载体上的呈现。

**关键提醒**：**一次只出一面**。六面展开图不能靠一张图，需按面分别生成后在排版软件里合（详见 `carrier-guide.md`「平台能力边界」）。

**提示词模板（单面）**：

```
[载体：六面礼盒正面 / 顶面 / 亚克力冰箱贴 6×6]，[角度：45 度俯视 / 正视平视]，
[可见面：只拍正面，其余面不要进入画面（同框多面会被拍成三面可见）]，
[底色与配色]，[纹样内容：单元主纹 + 一圈边框]，纹样位置与比例准确，纹样不压外轮廓与开窗线，
纹样完整不变形、图案不重绘，
[工艺质感：白卡纸哑光覆膜 / 局部烫金 / UV 凸起 / 亚克力通透感]，
棚拍柔光、干净背景，商业产品摄影，[质量词]
```

**负面词**：见下方「产品静物」组，额外加 `多面展开图, 边缘切割纹样`。

**参数**：1:1 或 3:4；风格强度低；细节强度中。

---

### 6C 包袋（托特 / 水桶 / 腋下包）

**用途**：看纹样落在包体上的位置、避让与整体调性。

**提示词模板**：

```
[包型：帆布托特 / 牛皮水桶 / 尼龙腋下包]，[材质：重磅帆布 / 光面牛皮 / 哑光尼龙]，
正面完整展示，[构图：单肩悬挂 / 平放侧立 / 微俯拍]，
纹样位于[正面中心 C 位 / 下半满铺 / 单侧局部]，避开缝线、压线与五金位，
纹样完整不变形、图案不重绘，
自然褶皱与真实阴影，[背景：浅灰背景 / 极简室内]，
商业产品摄影，[质量词]
```

**参数**：3:4（竖版）；风格强度低；细节强度中高。

## 场景七：服饰品载体（云肩 / 首饰 / 手提包）

> **统一前提：无人物。** 云肩用悬挂或平铺，首饰用微距或置于素色台面，包袋见 6C。

### 7A 云肩

**用途**：看纹样在云肩形制上的骨格顺应与刺绣质感。

**提示词模板**：

```
[云肩形制：如意云头四片 / 放射八片]，[展示方式：平铺展开 / 挂于无头人台或木质衣架，颈部开口处只见缎面内衬，不出现衣架杆与人台颈]，
[底色与配色]，纹样随轮廓分布，采用发射骨格，边缘一圈二方连续带，
[工艺质感：平绣细密 / 盘金勾边 / 贴布拼色]，
纹样完整不变形、图案不重绘，轮廓清晰、片与片之间的分割线可见，
博物馆式静物陈列，浅灰背景，柔和顶光，[质量词]
```

**关键约束**：不要让纹样横跨片与片的接缝；边缘带对应实物滚边/流苏位；悬挂时颈部开口是最容易翻车处——露衣架杆会看成「没脖子的人台」，宁可用平铺。

**实测**：四片悬挂一次出图通过（分割线清晰、无人物）；颈部露木质衣架一处瑕疵，约束已补进模板。

---

### 7B 首饰（胸针 / 耳饰 / 项圈 / 发饰）

**用途**：看纹样缩到 1–5 cm 后的可辨性——这一场景**只能走二级单元或三级剪影**。

**提示词模板**：

```
[品类：金属胸针 / 珐琅耳饰 / 刺绣项圈 / 发夹]，[尺寸感：置于素色台面 / 旁置参考尺度物]，
[纹样：单元素提取，外轮廓清晰 + 内部 1–2 条结构线]，
[工艺质感：珐琅填色 / 滴胶封层 / 金属蚀刻线 / 米珠刺绣]，
微距镜头，浅景深，纹样完整不变形、图案不重绘，
干净背景，珠宝商业摄影，[质量词]
```

**关键约束**：元素数越少越好（建议 1–3 个）；细线在生成阶段必然丢失，需后期矢量重绘。

---

### 7C 手提包与配饰（腰带 / 发饰 / 挂饰）

与 6C 同法，把"包型"换成对应品类，额外写一句 `避让五金与结构线`。

## 参数对照

| 场景 | 推荐比例 | 风格强度 | 细节强度 | 为什么 |
|---|---|---|---|---|
| 6A 丝巾/抱枕平铺 | 1:1 | 低 | 中高 | 平铺可控，重点是纹样完整与材质 |
| 6B 礼盒/冰箱贴 | 1:1 或 3:4 | 低 | 中 | 单面构图，不要让模型自由发挥 |
| 6C 包袋 | 3:4 | 低 | 中高 | 竖版看整体比例与避让 |
| 7A 云肩 | 1:1 | 低 | 高 | 刺绣质感与轮廓顺应都要看清 |
| 7B 首饰 | 1:1 | 低 | 极高 | 微距，细节丢不起 |

> 风格强度一律偏低：这一环要"忠实搬运"，不要"二次创作"。

## 负面提示词（产品 · 服饰品）

**产品静物（6A–6C）**：

```
person, model, human, hand holding, portrait, face,
cluttered background, busy scene, props unrelated,
warped pattern, redrawn pattern, pattern distortion,
shiny plastic texture, fake fabric, cgi look,
extra text, logo, watermark, wrong proportion, distorted object
```

**服饰品（7A–7B）**：

```
person, model, human body, neck, wrist, mannequin with face, hand model with face,
cluttered background, jewelry box clutter,
warped pattern, redrawn pattern, blurred fine lines,
plastic texture, cheap metal look, cgi render,
extra text, watermark, wrong scale
```

> 中文对照：不出现人物/模特/人脸、背景干净、纹样不变形不重绘、无塑料感、无多余文字水印、比例正确。

## 常见坑

| 症状 | 原因 | 改法 |
|---|---|---|
| 纹样被随机贴到边缘或缩得很小 | 没写纹样位置与占比 | 补"纹样位于正面中心、占正面宽度约 X%" |
| 纹样被"改良"了 | 缺防漂移句 | 加 `纹样完整不变形、图案不重绘` |
| 出现模特或手 | 未声明无人物 | 加 `无人台、无模特、无人物手部` |
| 包袋图案被五金压住 | 未写避让 | 加 `避开五金位与压线` |
| 首饰细节全糊 | 用了整幅纹样 | 降到单元/剪影（见 `carrier-guide.md` 降维规则） |
| 礼盒像斜拍的怪盒子 | 想要多面却只写"礼盒" | 明确"仅展示正面"，其余面按面单独出 |
| 画面出现品牌字 | 写了"文字清晰" | 删掉文字相关要求 |

- 【已出图实测】7A 云肩（四片悬挂）：四片分割线清晰、无人物、盘金勾边成立；颈部开口露出木质衣架一处瑕疵（已补约束）。
