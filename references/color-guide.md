## 快速判断规则

1. **三要素建议至少统一一个**：明度接近 / 纯度接近 / 色相邻近，否则容易显乱
2. **想要高级感** → 降纯度（灰调、莫兰迪）
3. **想要年轻感** → 提明度（浅调、亮调）
4. **去掉颜色只看黑白灰，构成是否依然成立** —— 这是配色能否独立成立的试金石

---

## 主辅点缀比例

约 **7:2:1**（经验参考，不是硬标准）：
- 主色约 70%（定调性）
- 辅助色约 20%（拉关系）
- 点缀色约 10%（跳出来）

> 波普风可以接近 5:5（但要靠元素大小或主次区分，避免完全均势），极简风可以是 9:1，看你想要什么效果。

## 风格→配色方向速查

| 想要的风格 | 配色方向 |
|---|---|
| 东方雅致 / 宋韵 | 低饱和、高明度、冷调为主 + 小面积暖点缀（金/藕荷） |
| 现代极简 / Celine 感 | 中性色为主、低饱和、小面积高亮点 |
| 暗黑浪漫 / McQueen | 深色调、低明度、酒红/墨绿/黑 + 金属点缀 |
| 复古摩登 / Art Deco | 金 + 深绿/酒红/藏蓝，高对比 |
| 自然诗意 / William Morris | 低饱和植物色、墨绿/赭石/米白 |
| 波普 / 年轻度假 | 高饱和撞色、平涂硬边 |

## 常见配色问题速查表

> 概览层直接能解决的小问题，不用翻深度文件。复杂情况再查 `color-pattern.md`。

| 症状 | 怎么判 | 怎么修（提示词加这一句） |
|---|---|---|
| **深色底上纹样看不清，糊成一团** | 主纹和底色明度差太小，暗纹沉进去 | 拉高明度对比："主纹比底色浅 2-3 度，或用提亮点缀色勾边"；深色底纹样优先用浅色（米白/金/银）而不是深色 |
| **太艳、太俗，像童装或地摊** | 饱和度太高，所有颜色都跳 | 整体降饱和："低饱和、莫兰迪色调、整体灰调"；加一句"去掉颜色只看黑白灰，构成依然成立"——这是试金石 |
| **配色太单调，只有一两个色，平** | 只有主色，没有辅助和点缀 | 按 7:2:1 补全：主色 70%（定调）+ 辅助色 20%（拉关系，同色系深浅）+ 点缀色 10%（跳出来，小面积金/银/高饱和） |
| **配色太花，五六种颜色打架** | 颜色太多，没有一个主调 | 砍到 3 色以内："主色 1 个 + 辅助色 1-2 个 + 点缀色 1 个"；统一明度或统一纯度（三要素至少一个统一） |
| **想要高级感，出来却廉价** | 颜色太亮、太纯、对比太硬 | 降纯度 + 提明度："低饱和高明度、柔和灰调"；避免纯黑纯白，用灰米/灰蓝/灰粉替代 |
| **想要年轻活力，出来却老气** | 颜色太暗、太灰、太沉 | 提明度："高明度、浅调、明亮清新"；可以用高饱和小面积点缀，但主色仍要亮 |
| **冷调太冷，像医院；暖调太暖，像饭店** | 全冷或全暖，没有平衡 | 冷暖比例定下来："冷色约 70% + 暖色点缀约 30%"（或反过来）；暖调风格里加一点冷色压一下 |
| **金/银色用错，亮金变铜金** | 金色太亮、太黄，像塑料 | 区分："泥金色（浅金、哑光、低饱和）"vs"亮金色（高反光、点缀小面积）"；中式宋韵用泥金，高定晚装用亮金 |
| **工艺配色不对，提花显脏、刺绣显闷** | 颜色超过工艺能表现的色数 | 提花：色数控制在 4-6 色以内，深底浅纹；刺绣：主纹用平色，渐变用套针；印花：渐变可以多色，实底别太深 |
| **上身显黑、显黄、脸色差** | 纹样靠近脸的颜色不对肤色 | 领口/胸口纹样建议避开荧光色和橘黄调；冷皮用冷调主色（蓝灰/藕荷），暖皮用暖调主色（米杏/驼） |
