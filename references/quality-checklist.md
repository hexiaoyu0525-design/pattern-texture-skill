# 纹样质量自检清单

生成纹样后，用这张清单快速自查。

> **重要前提**：下面每一条都不是绝对标准。先问自己——我想要的是什么风格？如果这个"问题"正好是我想要的，那就不用改。

---

## 构成检查

- [ ] 组织形式明确（单独/适合/二方连续/四方连续），没有混淆
- [ ] 骨式逻辑清晰（对称/均衡/发射/渐变），没有乱套
- [ ] 疏密符合我想要的风格吗？
  - 想要疏朗极简 → 检查是不是太满了
  - 想要满密繁复 → 检查是不是太疏了
  - 想要散点自由 → 不用检查疏密
- [ ] 正负形我需要它成立吗？
  - 想要正负形都好 → 检查底是不是好看
  - 想要正形为主 → 不用管底
- [ ] 点线面搭配符合我想要的风格吗？
  - 想要丰富层次 → 检查点线面是不是都有
  - 想要极简纯粹 → 可以全是点或全是面

---

## 配色检查

- [ ] 三要素我需要统一吗？
  - 想要和谐统一 → 检查明度/纯度/色相邻近
  - 想要混搭冲击 → 不用统一
- [ ] 主辅点缀比例符合我想要的风格吗？
  - 想要有主次 → 检查是不是五五开
  - 想要均衡配色 → 不用管比例
- [ ] 纯度调性符合我想要的吗？
  - 想要高级灰调 → 检查是不是太艳了
  - 想要高饱和波普 → 检查是不是太灰了
- [ ] 冷暖面积符合我想要的吗？
  - 想要统一调性 → 检查冷暖是不是对半开
  - 想要冷暖碰撞 → 不用管
- [ ] 构成靠颜色撑着吗？
  - 想要本身就有构成 → 调成黑白看看还成立吗
  - 就是要色彩渐变/晕染 → 不用管

---

## 工艺检查（这些是真问题）

- [ ] 线条粗细适合目标工艺吗？（刺绣细线容易断，不建议过细，经验参考，具体看工厂）
- [ ] 大面积实底色块太多吗？（一般不超过 30%，经验参考）
- [ ] 渐变色方式和工艺匹配吗？（数码印可以，丝网印阶调有限）
- [ ] 满身印花考虑身材修饰吗？（竖条显高，横条显胖）

---

## 去 AI 味检查（带风格前提）

- [ ] 我想要手工感吗？
  - 想要手工感 → 检查细节有没有自然变化
  - 想要精确干净 → 不用去AI味
- [ ] 细节有我想要的质感吗？
  - 想要手绘感 → 检查是不是太完美了
  - 想要几何精确 → 不用管
