## 七、颜色的文化语义与场合

同一套配色，换个场合就是错的。这一节不讲审美，只讲"这个色在这个场合意味着什么"——做婚礼、丧仪、年节、国礼、宗教题材、跨文化输出时要先过这一关。

### 7.1 单色的语义

| 色 | 中国传统语义 | 现代／商业语义 | 明显的坑 |
|---|---|---|---|
| **正红** | 喜庆、婚嫁、本命年、辟邪 | 促销、警示、力量 | 丧仪场合大面积正红为忌；商务正式场合大面积红显压迫 |
| **明黄** | 历代等级色（长期为帝王专用） | 尊贵、警示（交通）、童趣 | 日常成衣大面积明黄＝舞台感；与正红同面积并置＝年画 |
| **白** | 传统丧服色（素服、孝服） | 洁净、极简、西式婚纱 | 中式婚礼不用全白；白＋白＋白的三层白＝没骨架 |
| **黑** | 庄重、肃穆、丧仪（部分场合） | 高级、酷、机能 | 中式喜庆场合大面积纯黑不吉；黑＋朱红才是礼服正解 |
| **青／蓝** | 文人（石青、天青）、民间（蓝印花布） | 专业、冷静、科技 | 医疗场景的"医院蓝"要避开，配灰绿更冷 |
| **绿** | 民间（唐宋婚服"红男绿女"）、草木 | 环保、健康、运动 | 伊斯兰文化里绿色为神圣色，慎作装饰性跳色 |
| **紫** | 等级色（唐制三品以上服紫）、祥瑞 | 神秘、女性向 | 与金并置易滑向俗艳宫廷，需降纯度 |
| **金／银** | 富贵、礼制；泥金与亮金的分工见 0.5 | 奢华、节庆 | 浅底用金显脏；棉麻休闲料用金线显假 |

### 7.2 场合矩阵

| 场合 | 推荐 | 慎用 |
|---|---|---|
| 中式婚礼 | 正红＋金＋少量青绿点缀；"红男绿女"可作传统考据 | 全白、大面积黑、荧光色 |
| 丧仪／追思 | 白、黑、灰、藏青；素色、少花或无花 | 正红、明黄、亮金、大花满铺 |
| 春节／年节 | 红＋金＋少量宝蓝；团花、缠枝、福字 | 大面积冷灰、莫兰迪灰调（没年味） |
| 商务／通勤 | 藏青、灰、驼、米白；同类或邻近色，低对比 | 荧光、大面积正红、金银线 |
| 童装 | 高明度、邻近色，可高饱和小面积点缀 | 大面积黑、低明度灰（显压抑） |
| 舞台／秀场 | 强对比、金属、高纯度小面积 | 低饱和灰调（远看消失） |
| 国礼／文创 | 传统色的低饱和版本（天青、藕荷、茶褐、泥金） | 网红色堆砌、彩虹配色 |
| 跨文化输出 | 中性色打底（米、灰、驼）＋局部语义色（≤15%） | 直接搬正红／明黄／大绿（语义在不同文化里相反） |

### 7.3 三条使用原则

1. **语义色只做局部**：有明确文化含义的色（正红、明黄、金）面积压到 15% 以内，其余用中性色托——语义读得到，又不至于压场。
2. **换市场换色，不换图**：骨格、母题不动，只改地色与语义色，这是成本最低的本地化。
3. **不确定就降饱和**：低饱和的传统色（灰调石青、灰调朱红）跨场合、跨文化的容错率最高。
