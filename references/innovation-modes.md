### 模式 01｜骨格提取

**定义**：只拿走纹样的骨骼节奏（对称、重复单元、放射角度、疏密梯度），把具象内容全部替换成新元素或抽象图形——留下来的是"骨"，丢掉的是"皮"。

**操作步骤**：
1. 把参考纹样**灰度化+高斯模糊**到只能看见大结构（看不清花瓣叶脉）。
2. 描出**重复单元**和**对称轴/对称中心**；数清楚一个单元里有几个主点、几条主线、几个层级。
3. 把"骨"单独画出来（比如：一个单元 4 个放射点 + 1 条对角连线）。
4. 用新元素（几何圆点、新植物、抽象色块）**按同样节奏填进去**——节奏建议 1:1 复刻原骨。
5. 缩小到 5cm 看一眼：如果节奏和原参考一致，骨格提取就成了。

**案例**：
- 宋代缠枝莲四方连续 → 把莲花换成几何圆点，藤蔓换成 45° 斜直线 → 变成波普感现代几何四方连续。
- 哥特玫瑰窗十二瓣放射 → 提取十二放射节奏，每瓣换成不同大小的实心圆 → 变成现代品牌的波点放射纹。
- 苗族铜鼓纹"中心同心圆+四周放射" → 同心圆换成三条等距线，放射换成短斜线 → 变成极简民族风配饰暗纹。

**适用场景**：现代极简品牌、丝巾、年轻女装、配饰暗纹、品牌底色。

**难度与风险**：中等。最容易踩的坑是**骨格数错**（放射角度 30° 还是 45° 搞错，节奏就散了）；其次是换元素后和原骨语言不搭（古典骨格配波普元素要靠配色拉）。

### 模式 02｜风格混搭

**定义**：把两种不同文化/时期/艺术运动的视觉语言，用同一套构成逻辑缝合在同一个纹样里——不是 A 纹+B 纹并排，而是 A 当骨架、B 当血肉。

**操作步骤**：
1. 选两个风格源，先定**谁当骨架、谁当血肉**（如 A 出骨格、B 出元素/配色）。
2. 写一句**翻译规则**："把 B 的元素全部拉成直线" / "给所有元素加 1px 黑边" / "全部平涂不渐变"。这句话是混搭不分裂的关键。
3. 先做一个**小单元**（5cm×5cm）试混，建议先不要直接满版试。
4. 检查：远看是一个风格，近看才能看出第二个风格的影子。如果远看就是两种风格打架，回到翻译规则。
5. 统一一套配色把两种语言锁住（通常用中性色压场）。

**案例**：
- 宋式折枝花（骨格）+ 孟菲斯（配色与几何块）→ 折枝骨架不变，花叶换成孟菲斯高饱和几何色块 → 年轻度假风印花。
- 波斯联珠纹（圆环结构）+ 欧普艺术（黑白闪烁）→ 圆环保留，环内填欧普视错觉条纹 → 前卫秀场丝巾。
- 凯尔特结（无限交织线条）+ 新艺术植物曲线 → 交织节奏不变，线条末端长出新艺术涡卷叶片 → 哥特浪漫系列。

**适用场景**：设计师品牌、跨界联名、年轻线、创意胶囊系列。

**难度与风险**：中等偏上。最大的坑是**两种风格各占一半**——没有主次就成了"拼盘"。其次是没有统一翻译规则，远看像拼贴而非融合。

### 模式 03｜解构重组

**定义**：把纹样拆成最小零件，丢掉原图构图，让零件沿错位/重叠/裁切规则重新组织——"似曾相识但又不一样"。

**操作步骤**：
1. 把参考纹样拆成**可识别的零件池**（花、叶、茎、边框、圆点）。
2. 把原图构图扔掉，只留零件。
3. 定一条**错位规则**：沿 45° 斜移 / 上下错位 1/3 / 只取半朵 / 沿衣身结构线裁切。
4. 让零件之间有**重叠、压叠、裁切**关系（至少两层叠压）。
5. 故意留 1-2 个"完整识别点"（一朵完整的花），让人看得出源头——不然就变成从零开始。

**案例**：
- 缠枝莲拆成花瓣/藤蔓/叶 → 花瓣单独成散点、藤蔓变成斜向引导线、叶子被画框裁切 → Margiela 式残缺感印花。
- 青花瓷拆成缠枝+鱼+云 → 三个元素各取一半互相穿插 → "半青花瓷"解构印花。
- Art Deco 几何拆成阶梯/射线/扇形 → 射线被切一半、扇形错位叠 → 前卫秀场几何。

**适用场景**：高定、先锋品牌（川久保玲、Margiela 逻辑）、秀场主打的艺术款。

**难度与风险**：高。两个坑：① 完全看不出源头等于从零开始，没有"解构"的快感；② 碎片太多导致远看显乱、近看没有重心。

### 模式 04｜材质转译

**定义**：把**一种工艺/材质的视觉特征**（不是图案本身），搬到另一种工艺/材质能实现的语言里。注意：转的是"质感语言"，不是"图案形状"。

**操作步骤**：
1. 选**源材质**（苏绣盘金、蜡染冰裂纹、青花瓷釉、漆器犀皮、扎染晕染）。
2. 提炼它的 **2-3 个核心视觉特征**（如蜡染=随机裂纹+边缘晕染；刺绣=线密度差+立体压边）。
3. 选**目标材质**（数码印花、提花、激光镂空、植绒）。
4. 问自己：目标工艺能不能把那 2-3 个特征模拟出来？如果做不出来建议换目标工艺。
5. 用目标工艺的语言把特征画出来，去掉源材质做不到的细节。

**案例**：
- 苏绣盘金"金线压边+缎面填色" → 数码印花（金色线条勾边 + 哑光色块填色）。
- 蜡染冰裂纹 → 水洗做旧（随机裂纹在布面自然晕开）。
- 青花瓷釉"铁锈斑" → 提花（用纱线密度差模拟釉色深浅斑点）。
- 漆器犀皮纹（一圈圈不同色层圆环）→ 数码印花（同心不同色圆环）。

**适用场景**：工艺实验系列、高端定制、材料创新胶囊、非遗活化款。

**难度与风险**：中等。最容易翻车的是**目标工艺做不出源材质的关键特征**——比如印花做不出刺绣的立体起伏，硬做就显"平"。必须先过 `craft-guide.md` 工艺可行性这一关。

### 模式 05｜古今对话

**定义**：同一题材做**两层叠加**——底层是古代画法线稿，上层是现代抽象色块，两层透叠产生"古在今中"的对话感。

**操作步骤**：
1. 选一个传统题材（团花、飞天、龙纹、缠枝）。
2. 先画一层**复古线稿**（用传统线描，透明度调到 30-40%）。
3. 上面画一层**现代抽象**（大色块、几何、水墨晕染，覆盖 60% 以上）。
4. 调整两层透明度差，让底图**隐约可见**但不抢戏——人眼能"认出"古图但不会一眼看清。
5. 加一套统一配色把两层拉到一起（通常用中性灰或单色）。

**案例**：
- 底层宋式团花线稿 + 上层现代抽象水墨晕染 → 团花轮廓被水墨打散但仍可辨。
- 底层敦煌飞天线稿 + 上层赛博朋克霓虹色块 → 飞天轮廓在霓虹色块里若隐若现。
- 底层清代龙纹 + 上层极简大几何圆 → 龙纹只露一角，其余被几何吃掉。

**适用场景**：国潮、文创、高端女装秀场、文化主题胶囊。

**难度与风险**：中等。坑是：① 两层完全不融合（古线和色块各画各的）；② 上层盖太多把传统元素吃掉，对话变成"独白"。

### 模式 06｜元素拼贴

**定义**：从多个完全不同来源各取**一个完整元素**（不解构），按平面设计拼贴逻辑组合成新纹样。和模式 03 的区别：**不解构，拿完整的**。

**操作步骤**：
1. 先定一个**主骨格**（四方连续网格 / 二方连续 / 散点）。
2. 从 3-5 个不同来源各取一个完整元素：A（植物）、B（器物）、C（建筑）、D（动物）。
3. 给所有元素套**同一个视觉语言**（统一勾黑边 / 统一平涂 / 统一水彩晕染 / 统一做旧）。
4. 让其中一个元素当**主锚点**占比稍大，其余做配角。
5. 远看是整体纹理，近看才看得出是不同来源的拼贴。

**案例**：
- 网格拼：宋代荷花 + 波斯飞鸟 + 哥特拱券 + 热带椰子树 → 统一勾线平涂 → 全球化度假风印花。
- 满版拼贴：咖啡杯 + 旧邮票 + 邮戳 + 钢笔 → 统一做旧 → 复古旅行风。
- 丝巾拼贴：博物馆文物图标 + 植物 + 星座 → 极简线描统一 → 艺术衍生品丝巾。

**适用场景**：丝巾、度假系列、文创、年轻品牌、艺术衍生品。

**难度与风险**：中等。坑：① 元素来源太多导致风格不统一；② 没有主锚点，远看像杂货铺；③ 元素拼得太满没有留白。

### 模式 07｜尺度夸张

**定义**：打破传统纹样的元素比例关系——把某个主角放大 3-5 倍，或把某元素缩到几乎看不见，制造陌生感和张力。

**操作步骤**：
1. 选一个传统纹样，找出里面的主角元素。
2. 把主角**放大到占满整个重复单元**（甚至超过单元被裁切），配角缩到 1/5 以下。
3. 或反过来：把配角**缩到极小、近乎看不见**当暗纹，远看是纯色近看才有细节。
4. 让放大的元素被**衣身结构线裁切**（肩线、腰线、袖口切过花瓣）。
5. 检查：远看是抽象大图形，近看才看出原纹样是什么。

**案例**：
- 传统牡丹 → 牡丹被放大到占满衣身 2/3，花瓣被肩线/腰线裁切 → 大花礼服印花（Dior 大花逻辑）。
- 传统回纹 → 回纹缩到极小当底纹 → 远看是纯色近看是高级暗纹提花。
- 缠枝莲 → 莲花缩到指甲盖大，藤蔓被放大成主视觉 → 藤蔓主导的现代曲线纹。

**适用场景**：礼服、大衣、大廓形外套、丝巾、西装暗纹。

**难度与风险**：低-中。坑：① 放大过头完全看不出原纹样是什么，变成普通大花；② 比例失调导致穿着显胖（大花位置没避开身体最宽处）。

### 模式 08｜视角转换

**定义**：用非常规视角（俯视、剖面、X 光、微距）重新表现传统题材——不是换元素，是换"看的方式"。

**操作步骤**：
1. 选一个题材（花、建筑、器物、动物）。
2. 选一个**非常规视角**：俯视 / 仰视 / 剖面 / 微距 / X 光 / 内视。
3. 按这个视角重新画它的结构（建议不要照搬平视的花卉图）。
4. 去掉夸张透视变形，只保留结构特征。
5. 把新视角下的结构套回二方/四方连续。

**案例**：
- 传统花卉 → 俯视花朵（看到花心、花蕊、花萼对称排列）→ 放射状团花。
- 青花瓷瓶 → 剖面（看到釉层、胎体、铁锈斑分层）→ 层纹印花。
- 斗拱 → X 光结构（看到榫卯节点）→ 现代建筑感几何。
- 蝴蝶翅膀 → 微距（看到鳞片规则排列）→ 细密肌理底纹。

**适用场景**：建筑主题系列、艺术款、配饰、男装几何线。

**难度与风险**：中等。坑：① 视角太学术导致像教科书插图不像服装；② 透视变形无法做成连续纹样。

### 模式 09｜媒介迁移

**定义**：把**完全不是纹样领域**的视觉语言（建筑立面、电路板、乐谱、地图、字体排版），翻译成可重复的面料纹样。

**操作步骤**：
1. 选一个非纹样媒介（建筑、乐谱、电路板、古地图、字体、工程图）。
2. 提取它的**线条语法**：直线网格 / 曲线 / 节点圆点 / 标注符号。
3. 把语法套进二方/四方连续。
4. 加一个"面料味"元素软化（花卉、肌理、水彩晕染），建议不要让它像图纸。
5. 远看测试：像不像一块布？还是更像一张工程图？

**案例**：
- 包豪斯建筑立面 → 提取"横竖线+矩形色块" → 现代几何印花。
- 乐谱 → 提取五线谱+音符 → 音符二方连续边饰。
- 电路板 → 提取走线+节点圆点 → 赛博朋克底纹。
- 古地图 → 提取海岸线+地名标签 → 复古旅行丝巾。

**适用场景**：科技品牌、设计师品牌、主题胶囊、男装线。

**难度与风险**：中等。坑：① 直接抄图纸不像服装；② 元素太硬缺温度（建议加一个软化元素）。

### 模式 10｜情绪抽象

**定义**：从一个**情绪/氛围词**出发，不找具象图案，直接画它的形态（速度感、失重、灼烧、弥散、紧绷）。

**操作步骤**：
1. 定一个**情绪词**（焦虑、松弛、失重、灼烧、弥散、紧绷、漂浮）。
2. 用 3 个形态词描述它：焦虑 = 锯齿+密集+高对比；失重 = 斜向飘散+无重心。
3. 用抽象线条/色块把形态画满版。
4. 套进连续纹样（让抽象图形可重复）。
5. 检查：比具象图案更"有感觉"吗？没有就退回找具象。

**案例**：
- "失重" → 斜向飘散的不规则碎片 + 低饱和 → 羽绒感印花。
- "灼烧" → 橙红到黑的渐变 + 焦边不规则圆形 → 秋冬暗黑系列。
- "弥散" → 水彩晕染 + 无边界色块 → 浪漫婚纱系列。
- "紧绷" → 平行等距直线 + 高对比 → 极简职场系列。

**适用场景**：艺术系列、高定、情绪营销款、秀场主打。

**难度与风险**：高。坑：① 抽象到没有记忆点（情绪词太泛）；② 情绪词明确但执行出来和别人撞风格。

---

### 模式 11｜符号化简化

**定义**：把复杂纹样压缩到**图腾/图标级别**——3-5 笔能画完，缩小到 1cm 还能识别，成为品牌符号。

**操作步骤**：
1. 选一个传统纹样。
2. 只保留最识别的 1-2 个特征（莲花 = 三瓣轮廓 + 一点芯；凤凰 = 五根曲线）。
3. 其他全部删掉。
4. 用最粗线条画，填纯色。
5. 缩小到 1cm 测试：还能识别吗？不能就再加一笔。

**案例**：
- 复杂缠枝莲 → 三瓣莲花 + 一横茎 → 品牌 logo 级符号。
- 京剧脸谱 → 3 条线 + 1 个色块 → 国潮点缀。
- 凤凰 → 5 根曲线 → 品牌徽章。

**适用场景**：logo、徽章、局部点缀、配饰、包装。

**难度与风险**：低。坑：① 简化过头失去文化含义（变成随便一个图形）；② 太简显廉价（必须靠配色和工艺拉高级）。

### 模式 12｜叙事性纹样

**定义**：纹样里讲一个**场景或故事**——有时间性（采摘、市集、迁徙、四季更迭），远看是纹理，近看是叙事。

**操作步骤**：
1. 定一个**故事场景**（采茶、四季、迁徙、城市夜景、海洋生物）。
2. 把场景拆成 4-6 个**连续小画面**。
3. 按**二方连续**排列小画面（横条或竖条）。
4. 统一线条语言（全部线描 / 全部平涂）。
5. 远看是纹理，近看才是故事。

**案例**：
- 采茶故事（采摘→晾晒→炒制→包装）四个小画面 → 二方连续 → 茶主题文创丝巾。
- 四季更迭（春芽→夏花→秋叶→冬雪）→ 竖条连续 → 四季长巾。
- 迁徙（鸟→飞→停→筑巢）→ 二方连续 → 环保主题系列。

**适用场景**：文创、丝巾、长巾、主题胶囊、童装（讲故事尤其合适）。

**难度与风险**：中等。坑：① 画面太复杂远看显乱；② 故事性强但不适合满身（通常只适合边饰或长巾）。

### 模式 13｜随机生成

**定义**：借助**偶然效果**（撒点、泼溅、晕染、算法随机）生成不可复制的有机纹样——重点是"不要完美的对称"。

**操作步骤**：
1. 定一条**随机规则**（撒 100 个点半径 1-5mm / 泼 5 处墨 / 扎染随机晕开）。
2. 用工具或手绘制造偶然效果（建议不要手绘得太规整）。
3. 提取其中**好看的局部**（不是整张都用）。
4. 修正重复单元让它能**四方连续**（随机不是乱，边界要能对齐）。
5. 控制随机密度：中间密、边缘疏，避免满版乱点。

**案例**：
- 水墨泼溅 → 提取 3 处泼痕组成四方连续 → 新中式水墨印花。
- 扎染随机晕染 → 提取一块当重复单元 → 扎染感印花。
- 算法随机点阵 → 控制密度梯度（肩颈密、躯干疏）→ 现代科技底纹。

**适用场景**：秋冬、艺术系列、配饰、新中式、天然面料。

**难度与风险**：中等。坑：① 随机过头无法连续（边界对不上）；② AI 生成的随机显塑料（建议加手工随机感）。

### 模式 14｜跨文化融合

**定义**：把两个**对等地位**的非西方文化纹样语言融合。和模式 02 的区别：风格混搭通常是"传统+现代"，跨文化融合是"两种异质文化**对等对话**"（如苗族+摩洛哥、波斯+中国）。

**操作步骤**：
1. 选两个文化源（如苗族蜡染 + 摩洛哥 Zellige、波斯地毯 + 中国缠枝）。
2. 找出两者**共同的视觉 DNA**（都爱几何 / 都爱放射 / 都爱卷草）。
3. 定一个**共同骨架**（用共同 DNA 当中线）。
4. 把两种元素按节奏**交替**（A-B-A-B），建议不要 A 占一面 B 占一面。
5. 用**第三方中性配色**拉通（建议不要用 A 文化的配色，也不要用 B 文化的配色）。

**案例**：
- 苗族蜡染几何 + 摩洛哥 Zellige 瓷砖 → 都是几何，按四方连续交替 → 度假风印花。
- 波斯地毯卷草 + 中国缠枝莲 → 都是卷曲枝蔓，让两种卷草互卷 → 丝路主题。
- 印第安织带几何 + 苏格兰格纹 → 都是直线 → 格纹织带。

**适用场景**：全球化品牌、度假系列、文化主题胶囊、国际展会款。

**难度与风险**：高。坑：① **文化挪用**（不理解文化符号就随便用，必须先查文化含义）；② 两种元素各占一半像拼盘（建议找到共同 DNA 才融得动）。

### 模式 15｜生物形态仿生

**定义**：从**自然微观结构**（细胞、叶脉、晶体、鳞片、珊瑚）提取纹样——不是画花画草，是画"花和草的底层结构"。

**操作步骤**：
1. 选一个自然微观结构（叶脉、细胞、蝴蝶鳞片、蜂巢、珊瑚、雪花）。
2. 用显微图或高清照片观察它的**重复单元**。
3. 提取结构规则（叶脉 = 主脉 + 侧脉 60° 角；蜂巢 = 六边形 120° 内角）。
4. 抽象成几何化线条（建议不要画得像科普插图）。
5. 套进面料，加一个面料味元素软化。

**案例**：
- 叶脉 → 主脉 + 侧脉 60° 角 → 现代几何曲线纹。
- 蝴蝶鳞片 → 规则排列 → 细密底纹提花。
- 细胞分裂 → 放射状小圆 → 生物感印花。
- 蜂巢 → 六边形 → 科技感底纹。

**适用场景**：环保主题、科技品牌、天然面料、春夏系列。

**难度与风险**：低-中。坑：① 画得太像科普插图（建议抽象化）；② 没有服装温度（加花卉或肌理软化）。

### 多模式组合方法（复杂纹样必看）

**关键认知**：复杂繁复的高级纹样，从来不是单种模式做出来的，而是**多种模式叠加**出来的。

#### 按复杂度选模式数量

| 复杂度 | 模式数量 | 适用场景 |
|---|---|---|
| **低（简约日常）** | 1 种 | T恤、日常款、极简风 |
| **中（成衣主力）** | 2 种 | 连衣裙、衬衫、常规款 |
| **高（高级繁复）** | 3-5 种 | 高定、礼服、重工款、系列主纹 |

#### 组合的核心原则：有主有次，分层叠加

多种模式叠加不是乱堆，是**分层**：

| 层级 | 作用 | 用什么模式 |
|---|---|---|
| **第一层（底层）** | 定骨架 | 01 骨格提取、11 符号化简化 |
| **第二层（中层）** | 定风格 | 02 风格混搭、05 古今对话、14 跨文化融合 |
| **第三层（表层）** | 定细节 | 04 材质转译、06 元素拼贴、08 视角转换 |
| **第四层（点缀）** | 定亮点 | 07 尺度夸张、10 情绪抽象、13 随机生成 |

**例子**：宋韵新生纹样
- 第一层：01 骨格提取（宋式折枝骨格）
- 第二层：02 风格混搭（宋式 + 现代极简）+ 05 古今对话
- 第三层：04 材质转译（传统花卉 → 现代线条）
- 第四层：13 随机生成（手工感随机变化）

= 4种模式叠加，做出高级繁复的效果。

#### 常见的经典组合

| 组合 | 效果 | 适用 |
|---|---|---|
| 骨格提取 + 风格混搭 | 传统骨格 + 现代风格 | 国潮、文化活化 |
| 古今对话 + 材质转译 | 传统元素 + 现代材质 | 新中式、高端品牌 |
| 解构重组 + 随机生成 | 解构变形 + 手工随机 | 先锋、高定 |
| 元素拼贴 + 叙事性纹样 | 多元素拼贴 + 故事感 | 丝巾、度假风 |
| 情绪抽象 + 符号化简化 | 情绪表达 + 极简符号 | 极简、艺术品牌 |

**注意**：叠加越多，越要控制主次——主模式建议控制在1-2个，其他都是辅助。所有模式都抢戏 = 乱。
