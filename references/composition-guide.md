## 按组织形式分类

| 形式 | 定义 | 典型用法 | 深入了解 |
|---|---|---|---|
| **单独纹样** | 独立存在，不连续延伸 | 胸饰、口袋装饰、后背单独图案 | → `composition-pattern.md` |
| **适合纹样** | 适应特定外形轮廓 | 团花、角花、边饰、徽章 | → `composition-pattern.md` |
| **二方连续** | 沿一个方向重复，呈带状 | 领口、袖口、下摆、门襟、腰带 | → `composition-pattern.md` |
| **四方连续** | 上下左右四个方向无限重复 | 满身印花、连衣裙面料、西装面料 | → `composition-pattern.md` |
| **边缘纹样** | 专门用于边缘装饰 | 门襟、袋口、裙边、领口 | → `composition-pattern.md` |
| **地纹+浮纹** | 底纹+主纹两层叠加 | 宋锦、云锦、高级提花 | → `composition-pattern.md` |

| 骨式 | 定义 | 视觉感受 | 深入了解 |
|---|---|---|---|
| **对称式** | 左右/上下/旋转镜像 | 稳定、传统、庄重 | → `composition-pattern.md` |

## 平面构成法则（速览）

| 法则 | 判断参考（不是硬标准） | 深入了解 |
|---|---|---|
| **点线面** | 一般来说点线面搭配会更丰富，但极简风格可以只用点或只用面 | → `composition-pattern.md` |
| **对比与调和** | 7:3（70%统一+30%对比）是比较稳妥的比例，但波普风可以是5:5，极简风可以是9:1，看你想要什么效果 | → `composition-pattern.md` |
| **节奏与韵律** | 连续纹样一般要有疏密节奏，但几何网格风格可以平均分布，看风格 | → `composition-pattern.md` |
| **正负形平衡** | 正负形都成立是比较高级的做法，但正形为主、底为空白也可以，看设计需求 | → `composition-pattern.md` |

## 复杂度分级标准

| 等级 | 纹样数量 | 细节密度 | 适用工艺 | 典型场景 |
|---|---|---|---|---|
| **低** | 3-5个主要单元 | 简洁，少细节 | 数码印花、简单刺绣 | 日常T恤、简约款 |
| **中** | 8-15个单元 | 中等细节，有层次 | 数码印、丝网印、平绣 | 日常成衣、连衣裙 |
| **高** | 20-40个单元 | 繁复，多层叠加 | 提花、盘金绣、织锦 | 高定礼服、西装面料 |
| **极繁** | 50+ | 满铺，无空白 | 云锦、苏绣、重工刺绣 | 博物馆藏品、顶级高定 |

**注意**：复杂度越高，工艺成本越高，落地难度越大。日常成衣建议从中低复杂度起步。

## 常见问题速查表

> 概览层直接能解决的小问题，不用翻深度文件。复杂情况再查 `composition-pattern.md`。

| 症状 | 怎么判 | 怎么修（提示词加这一句） |
|---|---|---|
| **四方连续拼不上，四条边对不齐** | 出的图边缘图案断在一半，上下左右接不上 | 明确"四方连续、上下左右四边无缝拼接、单元重复排列"；必要时先出一个 2×2 拼贴图验证拼接 |
| **太满、太密，喘不过气** | 整张图没有空白，元素挤在一起 | 降密度："中低密度，纹样占比 30-40%，留出明显空白，有呼吸感"；删掉"繁复""丰富"等词 |
| **太散、东一块西一块，不成形** | 元素之间没有组织，随便散着 | 定骨式："散点式四方连续，主纹单元间距均匀""对称式排布"；给单元大小（"主纹单元约 5cm 见方"） |
| **骨式选错了，风格不对** | 想要清雅宋式，出来却像波斯地毯 | 宋式/东方雅致 → 用散点式 / 折枝式 / 疏朗均衡；波斯/民族 → 用中心发射 / 对称满铺；现代极简 → 用网格 / 均匀重复。先在脑子里定"骨式关键词"再写提示词 |
| **正负形不清，纹样糊在一起** | 主纹和地纹分不清，远看一团 | 拉开明度对比："主纹比地纹深一度或浅一度""地纹极淡，几乎看不见"；地纹要退到背景里 |
| **疏密节奏乱，有的地方挤有的地方空** | 没有节奏，元素大小距离全随机 | 定疏密："上疏下密 / 中心密四周疏 / 等距重复"；主纹大、点缀小，大小错落 |
| **点线面没搭配，画面单调** | 只有点，或者只有面，没有线 | 加一句"点（花蕊/小点）+ 线（枝叶/脉络）+ 面（主色块）三层搭配"；极简风可以只用面 |
| **复杂度失控，要么太简要么太繁** | 想要中等，出来要么 3 个元素要么 50 个 | 直接写数量："中等复杂度，8-15 个主纹单元"；高定再写"20-40 个单元多层叠加" |
| **满身印花显胖 / 显乱** | 穿在身上横向拉伸、视觉膨胀 | 用竖向骨式（竖条 / 纵向二方连续）+ 中低密度；避免横向大花和圆形满铺 |

> 配色问题见下方 color-guide.md 末尾的"常见配色问题速查表"。
