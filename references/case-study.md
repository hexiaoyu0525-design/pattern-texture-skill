# 实战案例：宋韵新生纹样设计

## 案例背景

**需求**：设计一个"宋韵新生"主题的服装纹样，用于春夏女装系列。
**目标**：不是照搬宋代纹样，而是用现代设计语言重新演绎宋代美学。
**用途**：连衣裙、衬衫、丝巾等多种单品。

---

## 第一步：定义情绪与氛围

**需求拆解**：
- "宋韵" → 宋代美学、清雅、内敛、文人感
- "新生" → 现代、简约、有当代感

**情绪关键词**：
- 清雅、内敛、留白
- 现代极简、东方雅致
- 低饱和、高明度

**氛围参考**：
- 汝窑天青色
- 宋代山水画的疏朗感
- 书房的安静氛围

---

## 第二步：定义创新点

**创新模式选择**：模式 02（风格混搭）+ 模式 05（古今对话）

**创新点**：
- 宋代折枝花卉的骨格 + 现代极简的线条语言
- 不是工笔画的具象花瓣，而是简化的线条+色块
- 保留宋式的清雅调性，但用现代的设计手法

**为什么不是直接照搬宋代纹样**：
- 直接照搬 = 没有创新，像文物复刻
- 提取骨格 + 现代演绎 = 有设计思考，有当代感

---

## 第三步：解构灵感原料

| 来源 | 提取什么 | 丢掉什么 |
|---|---|---|
| **宋代折枝花卉** | "一枝一花+枝叶"的舒展构图、疏朗的疏密关系 | 具象花瓣细节、工笔的细腻笔触 |
| **宋锦锦地开光** | 底纹+主纹两层结构、疏密对比 | 繁复的织锦纹样、浓郁配色 |
| **汝窑天青色** | 低饱和的蓝灰色调、温润质感 | 瓷器的器形 |
| **宋代山水** | 留白的呼吸感、虚实节奏 | 山水的具体内容 |

---

## 第四步：层次化构成设计

**三层结构**：

| 层次 | 内容 | 密度 | 颜色 |
|---|---|---|---|
| **底层（地纹）** | 极细几何锦地纹（回纹变体，淡到几乎看不见） | 高密度、低对比 | 比主色浅一度的同色系 |
| **中层（主纹）** | 折枝花卉（简化线条+色块，一枝一花枝叶舒展） | 中密度、散点式 | 天青色主调 |
| **顶层（点缀）** | 花蕊/叶脉关键点的浅金点缀 | 低密度、高对比 | 泥金色，小面积 |

**骨格**：散点式四方连续，疏密有致，有呼吸感

**为什么是三层结构**：
- 只有一层 → 平、廉价、没有层次
- 三层 → 有底纹、有主纹、有点缀，高级感出来了

---

## 第五步：配色方案设计

**主色**：天青色（低饱和蓝灰，像汝窑）
**辅助色**：月白 + 藕荷色（淡粉紫）
**点缀色**：泥金色（浅金，不是亮金）

**调性**：
- 低饱和、高明度
- 冷调为主（约 70% 冷色），暖色点缀（约 30% 藕荷+金）

**配色逻辑**：
- 整体是宋式的清雅
- 但藕荷色和金色增加了现代感和温度
- 不会太冷，也不会太艳

---

## 第六步：工艺与肌理叠加

**主工艺**：数码印花（中层折枝花卉）
**点缀工艺**：局部烫金（顶层花蕊、叶脉关键点）
**面料建议**：棉麻混纺或真丝双绉

**工艺层次**：
- 底层：印花（淡色地纹）
- 中层：印花（主纹）
- 顶层：烫金（小面积点缀，增加高级感）

**为什么不用满身刺绣**：
- 满身刺绣太贵，不日常
- 印底纹 + 局部烫金 = 成本可控，效果好

---

## 第八步：质量自检

| 检查项 | 结果 |
|---|---|
| 有没有层次？ | ✅ 三层结构（地纹+主纹+点缀） |
| 底纹是不是退下去了？ | ✅ 极淡，几乎看不见 |
| 主纹是不是明确焦点？ | ✅ 折枝花卉，中等密度 |
| 点缀是不是小面积但有存在感？ | ✅ 金色点缀，小面积但提亮 |
| 有没有明确主色调？ | ✅ 天青色为主 |
| 配色和主题匹配吗？ | ✅ 低饱和冷调，符合宋韵清雅 |
| 是不是纯印花？ | 是（+局部烫金点缀） |
| 有没有创新点？ | ✅ 宋式骨格 + 现代极简线条 |
| 是不是直接照搬传统？ | ✅ 不是，解构了宋代元素 |

---

## 最终成果

**纹样命名**：宋韵新生·折枝花卉锦地开光纹

**设计总结**：
- 不是宋代纹样的复刻，而是宋代美学的现代演绎
- 三层结构（地纹+主纹+烫金点缀），有层次有高级感
- 低饱和冷调配色，符合宋韵清雅的调性
- 数码印花+局部烫金，成本可控，适合日常成衣

---

## 从这个案例学到的

1. **先定义情绪，再选风格**：建议先定情绪再选，不建议一上来就说"我要宋式风格"，先想清楚要什么感觉
2. **创新点要明确**：从传统里提取什么、丢掉什么、加什么现代元素
3. **层次是高级感的来源**：不是一层铺满，是三层结构
4. **工艺要服务于设计**：不是越贵越好，是合适最重要
5. **出图要分三步**：平面→面料→成衣，一层一层看效果

## 示例二：反向解析——拿到一条品牌丝巾，怎么拆

**场景**：桌上有一条某轻奢品牌的真丝丝巾，客户说"我想要这种感觉，但不要直接抄"。

**拆解流程**（按 `analysis-workflow.md` 七步走）：

1. **先看整体**：远看 3 秒——主色调是哪几个？视觉焦点在哪？第一感觉是优雅 / 活泼 / 复古 / 现代？
2. **定组织形式**：是单独纹样（中心团花+四周边饰）还是四方连续？丝巾通常是"单独主纹 + 角隅 + 边饰"的组合，先圈出主纹边界。
3. **拆骨格**：主纹是对称还是旋转？是中心发射还是均衡排布？记录"骨格几何"（比如"四面对称+中心旋转 45°"），不要记具体画了什么花。
4. **抽配色**：把丝巾照片拖进取色器，记下主色 / 辅助色 / 点缀色的色值和大致面积比（通常 7:2:1）。
5. **判工艺**：真丝缎面+数码印花为主？有没有局部手工卷边？光泽是缎面本身还是烫金？
6. **总结可借鉴点**：骨格（对称+旋转）、配色比例（冷灰主+暖金点缀）、层次（主纹清晰、地纹极淡）——这三点是"学走"的部分。
7. **替换原创元素**：把丝巾上的具体花卉换成你自己的主题（比如改成东方折枝），保留骨格和配色逻辑，重画一遍。

**关键**：学的是"怎么排、怎么配"，不是"画了什么"。

## 示例三：翻车修复——生成的纹样太满 / 太散 / 配色不对

**场景**：提示词跑出来的四方连续纹样，要么密密麻麻塞满、要么东一块西一块散得不成形，要么颜色又艳又俗。

**用 `pattern-diagnosis.md` 定位→修**：

| 症状 | 可能病因 | 修正提示词怎么写 |
|---|---|---|
| **太满、没呼吸** | 密度没写清，默认满铺 | 加一句"中低密度，纹样占比 30-40%，留出明显空白，有呼吸感"；删掉"繁复""丰富"这类词 |
| **太散、不成形** | 骨格没指定，AI 自由发挥 | 明确骨格（"散点式四方连续，单元间距均匀""对称式排布"），并给一个主纹单元大小（"主纹单元约 5cm 见方"） |
| **拼接处对不上** | 没强调无缝 | 加"可无缝拼接，上下左右四边图案连续对齐"；必要时分两步出：先出一个 2×2 拼贴图验证 |
| **配色太艳、俗** | 没定调性，AI 用高饱和默认值 | 加"低饱和、莫兰迪色调，整体灰调""去掉颜色只看黑白灰也成立"；明确主色（"以天青灰为主色"） |
| **配色太单调、平** | 只给了主色，没给辅助和点缀 | 按 7:2:1 补全：主色 70% + 辅助色 20%（拉关系） + 点缀色 10%（跳出来，比如小面积金） |
| **有 AI 塑料感** | 太光滑、太对称 | 加"手工感细节，元素有自然随机变化，非机器完美对称""边缘有轻微手绘质感" |

**流程**：先对照 `quality-checklist.md` 四张清单逐项打勾 → 哪个症状命中 → 查 `pattern-diagnosis.md` 的"症状→病因→药方" → 只改提示词里对应那一句，不建议整段重写。
