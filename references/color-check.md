## 六、纹样配色的常见坑

每个坑都给"怎么判断 + 怎么改"。

### 6.1 显廉价的配色

| 坑 | 怎么判断 | 怎么改 |
|---|---|---|
| **高饱和 + 高对比 + 多色三者叠加** | 3 个以上色都在纯度 7–9，明度差都 >4 级 | 三选二：要么减色到 3 个，要么把一半色降纯度到 3–4，要么把明度差收到 3 级以内 |
| **灰度不一致（有的色加了灰、有的没加）** | 一个色是纯橙、旁边一个是灰粉，看起来"两个世界" | 全部色统一加灰——要么都加 20% 灰（莫兰迪化），要么都不加（纯艳波普），不要混 |
| **荧光色大面积使用** | 荧光粉/荧光绿/荧光橙占比 >10% | 压到 3% 以内做点睛；大面积用换成"灰荧光"（加 30% 灰） |
| **金/银用在不对的地方** | 浅底 + 大面积金；或休闲棉料 + 金线 | 金只配深底、只配小面积（3–5%）；棉 T 恤不建议金线 |
| **网红色堆砌** | 同时出现脏粉、牛油果绿、雾霾蓝、奶咖——每个单看都对，放一起"网感" | 只留 1 个网红色，其他换回中性色（米/灰/驼） |
| **所有色都带灰调但没主色** | 5 个莫兰迪色平铺，没有一个是"主" | 选一个色面积拉到 60% 以上，其他缩到点缀 |

### 6.2 显乱的配色

| 坑 | 怎么判断 | 怎么改 |
|---|---|---|
| **主辅不分（两个色各占 30%）** | 眯眼看看不出"哪个是主" | 把其中一个色面积压到 10% 以下，或合并到地纹里 |
| **点缀色太多** | 点缀色有 4–5 个，每个都"想跳" | 只留 1 个点缀色，其他改回主纹色系 |
| **色相差太小（主纹和地纹像一个色）** | 转灰度图，地和主的灰度差 <1.5 级 | 主纹明度拉大和地纹的距离（拉到 2.5 级以上） |
| **色相群超过 2 个** | 同时出现红、绿、蓝、黄——4 个不同色相群 | 砍到 2 个色相群（如红蓝 + 金），其他色全部归入这两群的邻近色 |
| **每个色都一样大** | 没有面积层级，色块像拼图 | 建立面积梯度：地 70% → 主 20% → 次主 7% → 点缀 3% |
| **骨格乱 + 色多** | 构图本身就散，颜色再加 4 个，彻底失控 | 先收骨格（对称/散点统一），再收颜色 |

### 6.3 显闷的配色

| 坑 | 怎么判断 | 怎么改 |
|---|---|---|
| **整体纯度都低** | 所有色纯度都在 2–3 级，没有一个跳出来 | 加 1 个纯度 7–8 级的点缀色（面积 3–5%）提神 |
| **明度差太小** | 所有色挤在明度 4–6 级中间 | 把地纹压到 2–3 级或提到 8–9 级，拉出两端 |
| **同色相近 3 个色** | 地、主、点缀都是灰蓝，分不清 | 点缀换成对比色（暖调或金属色） |
| **深底 + 深主** | 主纹比地纹还暗，"陷进去" | 主纹提亮 2–3 级，或加亮边勾线 |
| **没有中性色缓冲** | 全是有色相的色，没有黑/白/灰/米 | 加入 1 个中性色（米白、灰、驼）做过渡 |
| **纹样太满 + 色太灰** | 满地花 + 莫兰迪灰 = 水泥地 | 要么减密度（散点代替满地），要么提一个色的纯度 |

### 6.4 AI 生成纹样的典型配色问题

AI（包括本技能调用的生图模型）生成纹样时，配色高频出问题：

| 问题 | 表现 | 怎么改（提示词层面） |
|---|---|---|
| **颜色太多太杂** | 一个纹样里 8–10 个色，每个都艳 | 提示词明确"限定 3 色配色：藏青底 + 米白主纹 + 古铜金点缀"，并加负面词"多色、彩虹、花哨" |
| **没有明确主色** | 5 个色面积差不多，"花花的" | 提示词明确"主色占 70%、辅助色 25%、点缀 5%" |
| **默认彩虹色** | 生成出来是"七彩祥云"风 | 提示词明确写"低饱和、莫兰迪调性、同色系" |
| **深底上配亮粉/荧光** | AI 喜欢在深底上加亮粉、亮青 | 提示词指定"点缀用古铜金/米白，不用荧光色" |
| **配色和风格不匹配** | 宋韵纹样生成了高饱和红绿 | 提示词里把风格调性和配色绑定写："宋韵低饱和天青月白藕荷泥金" |
| **连续纹样接缝处色不一致** | 四方连续重复时，接缝颜色对不上 | 提示词强调"无缝四方连续、配色均匀一致"，出图后手动 tile 检查 |
| **点缀色过多且过大** | AI 把点缀画成了第二主纹 | 提示词明确"点缀色仅占 3–5%，小面积使用" |

**AI 配色修正的核心原则**：不建议让 AI 自由发挥配色。**把色板写进提示词里**——明确给出"地纹 X 色、主纹 Y 色、点缀 Z 色"，AI 才不会乱来。模糊的"高级感配色"是 AI 配色翻车的第一原因。

### 6.5 症状速查（十条）

| 症状 | 怎么判 | 提示词加这一句 |
|---|---|---|
| 深底上纹样看不清 | 明度差太小，暗纹沉底 | 主纹比底色浅 2–3 度；深底用米白 / 金 / 银勾边 |
| 太艳、太俗 | 纯度全高，所有色都跳 | 低饱和、莫兰迪、整体灰调；加"去掉颜色构成仍成立" |
| 配色单调 | 只有主色，没辅色点缀 | 按 6:3:1 补全：主 60 + 辅 30（同色系深浅）+ 点缀 10（金/高饱和） |
| 太花（五六色打架） | 没有主调 | 砍到 3 色内；明度或纯度至少统一一个 |
| 想要高级却廉价 | 太亮、太纯、对比太硬 | 降纯度 + 提明度；用灰米 / 灰蓝 / 灰粉替代纯黑纯白 |
| 想要年轻却老气 | 太暗、太灰、太沉 | 高明度浅调；主色要亮，点缀可高饱和 |
| 冷调像医院 / 暖调像饭店 | 全冷或全暖 | 冷暖按 7:3 分配，剩下的那一头做点缀 |
| 金一用就像塑料 | 金色太亮太黄 | 区分泥金（哑光低饱和）与亮金（小面积高反光） |
| 工艺一换就显脏 | 色数超工艺上限 | 提花色数少、深底浅纹；刺绣主纹平色；印花可多色但实底别太深 |
| 上身显黑显黄 | 领口色不对肤色 | 避开荧光与橘黄；冷皮用蓝灰 / 藕荷，暖皮用米杏 / 驼 |

## 八、速查总表

### 8.1 三层配色数值速查

| 项目 | 推荐区间 |
|---|---|
| 地纹面积 | 70–85%（锦地纹可低至 65%） |
| 主纹面积 | 15–30% |
| 点缀纹面积 | 3–8%（上限 8%） |
| 地↔主明度差 | 弱对比 1.5–2.5 级 / 中对比 2.5–4 级 / 强对比 >4 级 |
| 地↔主纯度差 | 高级感 2–4 级（地灰主艳） |
| 主↔点缀明度差 | 点缀是全纹样最亮或最暗（二选一） |
| 色相差默认区间 | 邻近色 15–45°（最安全） |
| 冷暖面积比 | 7:3（不能对半开） |
| 补色面积比 | 85:15 ~ 90:10（绝不 50:50） |

### 8.2 深浅底切换速查

| | 深色底 | 浅色底 |
|---|---|---|
| 主纹明度 | 比地亮 2–4 级 | 比地暗 2–4 级 |
| 点缀色 | 金/银/米白 | 黑/深棕/墨色 |
| 主纹纯度 | 可高 1 级 | 降 1–2 级 |
| 最大风险 | 主纹过亮刺眼 | 主纹过浅发飘 |

### 8.3 复杂度 ↔ 配色策略

| 复杂度 | 色相差 | 明度差 | 纯度控制 |
|---|---|---|---|
| 低 | 可用邻近色到对比色低段（15–100°） | 拉大到 3–4 级 | 统一 |
| 中 | 邻近色 15–45° | 2.5–3.5 级 | 统一 |
| 高 | 收紧到同类／邻近（≤30°） | 拉大到 3–4 级 | 同族色 |
| 极繁 | 1–2 个色相群，色相差 ≤15° | 梯度拉开 | 严格同族 |

### 8.4 一眼诊断三色法

拿到一个纹样配色，按下面三步快速诊断：

1. **眯眼 3 秒**：整体是一个统一色调，还是五颜六色的花团？→ 花团就要减色。
2. **转灰度**：地和主纹的灰度差是否 >1.5 级？→ 不够就拉大明度差。
3. **看面积**：最大的色是不是占了 60% 以上？→ 没有主色就压出主色。

这三步过了，配色基本不会难看。剩下的就是风格调性的微调。

### 8.5 风格→配色速查表

直接查表出配色方案，不用自己推。

| 风格/调性 | 调性定位 | 主色 | 辅助色 | 点缀色 | 整体感觉 |
|---|---|---|---|---|---|
| **极简高级** | 灰中调（莫兰迪） | 米白/浅灰 | 灰蓝/灰粉 | 黑 | 克制、高级、留白多 |
| **暗黑哥特** | 灰深调 | 玄黑 | 酒红/古铜金 | 深紫 | 神秘、厚重、仪式感 |
| **宋韵雅致** | 中浅调（低饱和） | 天青/月白 | 藕荷/茶褐 | 泥金 | 清雅、内敛、文人感 |
| **中式华丽** | 深艳调 | 正红/藏蓝 | 石绿/泥金 | 明黄 | 浓郁、喜庆、宫廷感 |
| **波普活力** | 中艳调（高饱和） | 正红/明黄 | 宝蓝/草绿 | 黑白 | 跳跃、年轻、街头感 |
| **莫兰迪温柔** | 灰中调 | 灰粉/灰蓝 | 奶咖/灰绿 | 米白 | 柔和、治愈、奶油感 |
| **复古摩登（Art Deco）** | 高对比深调 | 金 | 深绿 / 酒红 / 藏蓝 | 米白 | 奢华、几何、黄金时代 |
| **自然诗意（Morris）** | 低饱和中调 | 墨绿 | 赭石 / 米白 | 灰蓝 | 植物感、田园、温和 |
| **街头潮酷** | 深艳调 | 黑/藏青 | 荧光橙/荧光绿 | 银 | 酷、冲击、机能感 |
| **田园清新** | 中浅调 | 奶白/浅绿 | 淡黄/浅粉 | 棕 | 自然、治愈、度假感 |
| **Art Deco摩登** | 中深调 | 黑/藏蓝 | 金/银 | 象牙白 | 奢华、几何、复古摩登 |
| **波西米亚** | 中艳调（暖调） | 土黄/橙红 | 松石绿/棕 | 玫红 | 自由、民族、度假感 |

**使用规则（经验参考，不是硬标准）**：
- 主色约占 60-70%，辅助色约 20-30%，点缀色约 5-10%（经验比例，不是绝对标准）
- 想要更高级 → 把主色纯度降一档（高→中，中→低）
- 想要更年轻 → 把明度提一档（低→中，中→高）
