# 快速卡：用户只给一句话时，给三个纹样方向

> 本技能的主体是**纹样本身**。载体（丝巾、抱枕、云肩）与展示视频只是"把纹样拿出来看"的手段——所以三张卡对比的是**纹样方案**（风格 + 骨格 + 密度 + 形式语言），不是"纹样×载体"的组合套餐。载体在最后展示时才定。
> 用途：用户从 0 开始，只丢一句大方向（"想要个东方的""做点敦煌感""清冷一点的"），或干脆说"随便来一个"。
> 什么时候别用：给了参考图 → 先解析再给方向（`design-workflow.md` 对话版·参考图分支）；点了具体风格/朝代/非遗 → 直接进流程。

## 1. 三种输入状态（先判，别猜）

| 状态 | 判据（用户说了什么） | 动作 |
|---|---|---|
| **A 明确** | 有风格词 / 朝代 / 非遗名 / 参考图 | 不问，直接进第 0 步或先解析参考图 |
| **B 半明确** | 有一句大方向（"东方""敦煌""清冷""复古""潮"），但没到具体风格 | 给默认方案 + "要换说编号"，直接开工 |
| **C 零想法** | 只有"来个纹样 / 随便 / 给我点灵感 / 你看着办" | 给三张纹样方向卡让他挑 |

**判据优先级**：参考图 > 具体风格词 > 一句大方向 > 语气。有参考图就是 A，不要再问他想要什么。

**B 状态怎么处理**：一句大方向已经够我推参数了（见 `design-workflow.md` 对话版“大方向→参数”表）。先复述他的方向、给出我的读法，再直接给一套方案，不停下来等确认。

## 2. 为什么给方案而不是问问题

零想法的人答不出"你要什么骨格/什么母题"——这正是他要你解决的问题。他能答的是"这三个方向哪个顺眼"。所以：

- ❌ "你想要什么风格？"——把问题推回给他
- ❌ "请提供：风格 / 骨格 / 配色 / 尺幅"——一次四问，像填表
- ✅ "三个方向，你挑一个；没想法就按①，我直接开始"

**节制**：一次只展开一层菜单，最多两轮。第三轮追问就是审讯，不如给默认开工。

## 3. 三层菜单（一层展开，不叠层）

### 3.1 菜单 A：大方向（最省事的入口）

| 选项 | 用户看到的话 | 我会往哪推 |
|---|---|---|
| ① 东方 / 传统 | 中国、日式、敦煌这一类 | 线主导、植物母题、留白、二方或缠枝或团花 |
| ② 现当代 | 干净、几何、潮、极简 | 几何化、双色、大负空间、网格重复 |
| ③ 民间 / 民族 | 浓艳、吉祥、手工感 | 高饱和撞色、吉祥母题、粗线、几何格 |
| ④ 说不清，给我看 | 我只是想先看几个方向 | 直接出三张卡（不用他答这层） |

### 3.2 菜单 B：形式语法四选（这才是真正决定"长什么样"的）

| 选项 | 用画面语言写，不用流派名 | 对应理论 |
|---|---|---|
| ① 疏朗清雅 | 一枝为主、大片留白、细线、低饱和三色 | 留白与线主导（`style-east-asian.md` 0.4） |
| ② 满密浓烈 | 满铺不留空、高饱和撞色、强对比 | 满密与强对比（`style-east-asian.md` 0.1、`style-global-tribal.md` 0.2） |
| ③ 几何克制 | 两三种几何、双色、负空间占一半、无渐变 | 几何化与负空间（`style-modern-contemporary.md` 0.3） |
| ④ 对称厚重 | 中轴对称、满密卷草、金与暗色、以面塑形 | 对称度与面积（`style-western-historic.md` 0.2） |

**注意**：选项标签用"看得见的画面"，不用"巴洛克/波普/解构"——零想法的用户不认识流派名，认识画面。流派名放在卡片的"依据"行里，让他事后能查。

### 3.3 菜单 C：成像气质（决定"贵不贵"，最后一层）

| 选项 | 画面后果 | 对应 |
|---|---|---|
| ① 印花平涂 | 干净、色块平、渐变可用、细节完整 | `craft-guide.md` 印花类 |
| ② 刺绣线迹 | 有针脚、随光变、有厚度、显贵 | 刺绣类 |
| ③ 提花织纹 | 织出来的、边缘阶梯、低调贵、曲线受限 | 织造类 |
| ④ 扎染 / 后整理 | 自然随机、边缘渗化、不可精确 | 后整理类 |

**一句提醒**：这一层选的不是载体，是**纹样的长相**——成像是工艺决定的，工艺定错，前面几层全白做（机制见 `craft-guide.md` 第 0 节）。

## 4. 三张卡的格式（直接抄）

以"想要个敦煌感的"为例：

```
① 【推荐】宝相团花 · 疏朗 · 矿物色
   画面：一朵宝相花居中，四周三枝折枝环绕，留白约四成，铁线勾勒，土红 / 石青 / 暖金
   依据：团花 + 折枝是敦煌织物最常见的组合，密而不堵（东方主线二：外来融合）
   代价：结构简单，可跳过线稿；放大到整幅仍读得出

② 缠枝满铺 · 密 · 矿物色
   画面：卷草为骨架，花朵沿波线错位排列，不留空，四边可拼
   依据：缠枝是"连续"最主流的骨格，适合大面积与布料（骨格：连缀）
   代价：必须给单元与重复向量，建议先出线稿，否则接缝半截断

③ 联珠几何 · 秩序 · 双色 + 金
   画面：联珠圆点阵叠菱形格，两色，边缘硬，无渐变
   依据：联珠是外来骨格本土化的典型，异域秩序感最强
   代价：极简易单调，全靠配色与密度撑
```

每张卡四样齐全：**风格走向 + 骨格与密度 + 一句依据 + 一句代价**（快不快、要不要线稿、会不会糊）。

- 三张卡的差别必须落在**骨格或密度**上，不能只是换个颜色——否则等于给了一个方案的三次微调（同质化自检见 `innovation-ops.md` 0.3）。
- 第①张固定标【推荐】并配一句"没想法就按①，我直接开始"，保证一句"就①"闭环。
- **不许三张全稳妥**：常规是两张稳妥 + 一张略冒险（解构、混搭、材质转译），冒险那张要写明风险，不包装成稳妥项。

## 5. 教学场景的菜单（讲的是差异，不是一张好图）

| 选项 | 产出 | 讲解点 |
|---|---|---|
| ① 讲骨格 | 同一母题换 4 种骨格，一组对照图 | 骨格决定秩序，母题只是内容 |
| ② 讲连续 | 同一单元做二方连续与四方连续两版 | 重复向量与接缝的差别 |
| ③ 讲线型 | 同一纹样换四种线型（游丝/铁线/兰叶/减笔） | 线型决定气质，不是粗细问题 |
| ④ 讲配色 | 同一纹样三套配色（面积比不同） | 面积比与纯度成反比 |
| ⑤ 讲落地 | 同一纹样在丝巾/抱枕/云肩上的降维对比 | 载体决定细节层级（最后一步） |

教学场景验收标准是"差异是否可讲解"，不是"图是否好看"。

## 6. 什么时候不要问

- 给了参考图 → 先解析（`analysis-workflow.md`），再给三条延展路线
- 说了风格名 / 朝代 / 非遗名 → 直接进第 1 步查库
- 说"快点 / 先出一版看看 / 无所谓" → 直接出默认方案，出完再问要不要调
- 已经问过一轮并得到回答 → 同类问题不再问第二轮
- 用户重复"随便/都行"两次以上 → 停止提问，按默认做到出图，附一句"不满意我再换"

## 7. 挑定之后接哪一步

| 状态 | 接哪 |
|---|---|
| A 明确 | 直接进该任务类型对应的文件；有参考图先走解析 |
| B 半明确 | 复述方向 + 给一套方案 → 进第 0 步（或快速路径直接上色） |
| C 零想法 | 出三张卡 → 挑定 → 进第 0 步；菜单 B 映射到 `style-east-asian.md` 等四份风格文件，菜单 C 映射到 `craft-guide` 对应章节 |

**载体问不提在这里**：卡片不绑定载体。等纹样定了、要展示时再问"要不要看它落在某个物件上的样子"（`carrier-guide.md`）。

## 8. 用户想"一步一步来" → 切逐步推荐

三张卡是**快速路径**。用户如果说"一步一步来 / 我想自己定 / 别一下给我三张 / 教我怎么选"，不要继续出卡，转 `references/design-workflow.md`：

- 七站：方向解读 → 风格与形式语法 → 母题与骨格 → 线型与层次 → 配色 → 成像工艺 → 出图与展示
- **每站给一个建议，不抛一个问题**：我建议（一个主选）+ 依据（对应哪条理论）+ 备选（两条 + 一句后果）
- 收尾用陈述句（"不改就按这个往下走"），不用疑问句；用户"嗯/继续/都行"即视为接受
- 两条路径共用同一份参数包，随时可切、切了不丢
