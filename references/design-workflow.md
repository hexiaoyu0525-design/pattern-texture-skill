# 创新设计工作流

从一个情绪/概念出发，一步步生成**有层次、有细节、高级感**的原创纹样。

**核心原则**：传统风格不是用来照搬的，是灵感原料。最终产物建议是**创新的、有设计思考的、复杂且高级的**。

> **这是推荐流程，不是唯一正确的**。你可以从任何一步开始，也可以根据自己的习惯调整顺序。这个流程是给新手的脚手架，熟了之后可以自由发挥。

## 0. 为什么是这八步（顺序的依据）

八步不是经验凑出来的顺序，它来自两条设计方法学：**双钻模型的发散—收敛节奏**，和**形态分析法的分解—重组—评价**。知道每一步是"发散"还是"收敛"，才知道什么时候该放开、什么时候必须锁死。

### 0.1 两条"钻"

| 轮次 | 发散（找可能） | 收敛（定一个） | 对应本文件 |
|---|---|---|---|
| 第一钻：问题 | 我要什么感觉、给谁、用在哪 | 定情绪与氛围（一句可复述的定调） | 第一步 |
| 第二钻：方案 | 创新模式与灵感原料的多路试探 | 定创新点、定骨格与构成、定配色、定工艺 | 第二至第六步 |

**节奏错位的典型翻车**：在第一步就收敛（"就做个敦煌风"），后面全部变成执行；或在第四步还在发散（不断换骨格），成品永远出不来。**发散只允许发生在标注为发散的那一步。**

### 0.2 顺序为什么不能倒：感觉 → 结构 → 工艺

三步之间有硬依赖，倒过来会反复返工：

1. **感觉先于结构**：同一骨格可以做出完全不同的气质（密铺细线 vs 疏朗粗线），先定调才能选骨格；先选骨格再想气质，等于让形式决定内容。
2. **结构先于工艺**：工艺是"成像机制"（见 `craft-guide.md` 第 0 节），它决定线条与边缘能保留到什么程度。结构没定就选工艺，工艺反过来会把结构吃掉。
3. **工艺先于提示词**：提示词是把已定的四件事（感觉、创新点、骨格构成、工艺肌理）翻译成语言。任何一件没定，提示词里就会出现形容词代替参数的空洞句。

### 0.3 每一步的性质（发散 / 收敛 / 锁定）

| 步 | 性质 | 该产出什么（判据） |
|---|---|---|
| 1 定义情绪 | 发散 → 收敛 | 一句能复述的定调（三个形容词以内） |
| 2 定义创新点 | 发散 → 收敛 | 选定的创新操作（换形/换义/换序/生成）与理由 |
| 3 解构灵感 | 发散 | 抽出的骨格与单元清单（不是参考图堆叠） |
| 4 层次化构成 | 收敛 | 骨格 + 单位 + 三层层次，锁死 |
| 5 配色 | 收敛 | 色阶与面积比，锁死 |
| 6 工艺肌理 | 收敛 | 成像机制 + 肌理层级，锁死 |
| 7 提示词 | 翻译 | 四件事全部落成可执行句 |
| 8 自检 | 评价 | 逐条对照清单，出问题回到对应步 |

### 0.4 回环的依据：症状决定回哪一步

判断回哪一步，看"改动会牵动谁"：

- 只是"不好看"→ 回第 4 步（构成）或第 5 步（配色）
- "气质不对"→ 回第 1 步，不要在配色上找补（气质错多半是定调错）
- "像别人的东西"→ 回第 2、3 步（创新操作或解构深度不够）
- "出图像但不像纹样"→ 回第 4 步（骨格或重复规则缺失）
- "细节全糊"→ 回第 6 步（工艺与肌理层级冲突）

## 设计总流程

```
定义情绪/氛围（我要什么感觉？）
    ↓
定义创新点（从哪里提取？怎么解构？怎么混搭？）
    ↓
解构灵感原料（从传统/自然/艺术里提取元素骨架）
    ↓
层次化构成设计（底纹+主纹+点缀，三层结构）
    ↓
高级感配色（低饱和、有层次、有对比但不刺眼）
    ↓
工艺与肌理叠加（不是纯印花，有工艺层次）
    ↓
输出提示词（套模板，直接出图）
    ↓
高级感自检（过一遍检查清单）
```

## 对话版：把八步压成七站（我陪用户走时用）

同一个流程，两种交付方式：**用户自己主导就走八步；我陪着走就压成七站**。七站不是另一套方法论，是我的提问与建议节奏。

### 七站 ↔ 八步对应

| 站 | 对应八步 | 只解决什么 |
|---|---|---|
| **S1 方向解读** | 步 1 | 他这句话到底指哪一路（东方？敦煌？清冷？） |
| **S2 风格与形式语法** | 步 1（定调 → 查库） | 落在哪一路，这一路内部怎么变 |
| — 创新点（步 2） | 步 2 | 在 S2 收尾用一句话问：动结构、换语言，还是两层都动 |
| **S3 母题与骨格** | 步 3 + 4 | 画什么 + 怎么排（核心站） |
| **S4 线型与层次** | 步 4 | 线型、层级、疏密 |
| **S5 配色** | 步 5 | 底色明度 + 三色与面积 |
| **S6 成像工艺** | 步 6 | 图案被什么方式做出来 |
| **S7 出图与展示** | 步 7 + 8 | 线稿或直上色 + 验收（展示可选） |

**为什么是七站而不是八步**：对话里步 3（解构灵感）与步 4（层次构成）是同一个决定的两面——单元里放什么、按什么排——合成一站；步 7/8 出图与自检也合成一站。步 2 创新点单独问一句，不单独占站。

### 每站的建议写法（五段）

**我建议**（一个主选，带编号）→ **依据**（一句，说明为什么这么选）→ **备选**（两条 + 一句后果）→ **提示**（2–3 条讲后果的）→ **判据**（满足了才进下一站）。

关键站的要点（其余按上面八步正文执行）：

- **S2**：必须问一句"不要什么"——反向排除比三个正向形容词有用；同一风格内部还有几何化、对称度、密度、线条四维可调。
- **S3**：一个单元最多两个母题；四方连续必须给单元 + 重复向量；骨格点 / 错位量 / 环绕方式三格别空着。
- **S4**：线型定气质（游丝细腻、铁线均匀、兰叶顿挫）；闭合完整是准入条件；单一线宽一定平。
- **S5**：主辅点缀约 6:3:1；碎小图案远看必发灰，主色要成片；换底不等于换色。
- **S6**：四种成像机制决定画面长相上限；提花曲线会被经纬台阶化；刺绣要写针法不只写颜色。
- **S7**：只看效果就直接上色、线稿不拦；要拼缝 / 系列 / 载体 / 视频才先出线稿；彩图已认可要转正式，走场景五情形 B 反推。

### 一句话大方向 → 参数

用户说的"东方""敦煌""清冷""复古""潮"都不是参数，是感觉。先翻译，再给建议。

| 用户说 | 翻译成参数 | 依据 |
|---|---|---|
| 东方 / 中国风 | 线主导、留白、植物母题、二方或缠枝或团花、低饱和或矿物色 | 中国纹样以线造型 |
| 敦煌 | 土红石青 + 暖金、卷草 + 团花 + 联珠、密铺、矿物色 | 外来融合主线：植物连续纹成熟、联珠外来骨格 |
| 清冷 / 高级灰 | 低饱和同色阶、大留白、几何化、细线、无渐变 | 明度差建层次、负空间比例 |
| 复古 / 老派 | 满密、中轴对称、暖暗色、以面塑形 | 对称度 + 密度两维 |
| 潮 / 年轻 | 高饱和、几何硬边、网格重复、符号化 | 商业符号的区隔逻辑 |
| 手作 / 质朴 | 不规则、点线混用、边缘渗化、天然色 | 后整理的随机来自物理过程 |
| 华丽 / 贵气 | 线迹或织造成像、金、满密、强光泽 | 刺绣针法决定反光、缎纹浮长 |
| 日式 | 季节题材、密小单元、不均齐留白（琳派）或素朴（侘寂） | 两套相反的形式逻辑 |
| 民族 / 部落 | 依经纬格排布的阶梯几何、横向条带分隔、边缘蜡染渗化 | 几何被工艺框出来 |

**翻译完立刻做三件事**：复述他的方向并说出我的读法 → 给一个主建议 + 两条备选 → 不停下来等确认。

### 有参考图时：先读结构，再给三条延展路线

1. **解析**（`analysis-workflow.md`）：骨格 → 组织 → 母题构成 → 密度 → 线型 → 配色 → 工艺暗示。
2. **结构读数一句**（让用户能核对）："这是四方连续，单元里一朵五瓣花 + 两片叶 + 一处点缀，密度中高，铁线描，深底浅纹，边缘干净。"
3. **三条基于这张图的延展路线**：

| 路线 | 动什么 | 适合 | 风险 |
|---|---|---|---|
| **R1 同结构换母题** | 保留骨格密度，换题材 | 要"像这张但不一样"，最稳 | 容易太像，需再动一处密度或线型 |
| **R2 同母题换骨格** | 保留题材，换秩序 | 做系列第二、三张 | 母题在小单元里会挤 |
| **R3 换形式语言** | 结构不动，换线型 + 配色 + 密度 | 同一套语言的新版本 | 识别度会掉，最需要线稿锁结构 |

日常交付推 R1 或 R2，做系列推 R3。

### 出口用陈述句，不用疑问句

每站收尾不写"这样可以吗"，改成陈述式通知：

> "我按这个走：宋式折枝 / 散点骨格 / 铁线描三层 / 浅底低饱和矿物色 / 数码印花。下一步配色我给三色，不改就往下；想改哪项，说编号。"

三件要素：**当前组合一句列清 / 下一步是什么 / 改的话怎么说**。

### 切换规则与分寸

- 用户说"直接出图 / 别问了 / 出吧" → 收口：已定照用、其余取默认、立刻到 S7。
- 用户说"嗯 / 继续 / 都行 / 你定" → 视为接受，直接进下一站，不重复确认。
- 想看别的方向 → 回当前站给三张纹样方向卡（`intake-guide.md`）。
- 全程最多 7 站；主建议被否两次 → 改出三张卡；连续两次"随便" → 停止逐站建议，按当前组合一路做到出图。
- 教学场景：每站附一句"换另一个会怎样"，因为要讲的是差异。

## 第一步：定义情绪与氛围

先不要想"用什么风格"，先想**你要什么感觉**。

### 情绪关键词表
| 想要的感觉 | 关键词方向 | 典型氛围 |
|---|---|---|
| **东方雅致** | 宋韵、文人、山水、留白、内敛 | 汝窑天青、山水画、宋代美学 |
| **暗黑浪漫** | 哥特、神秘、缠绕、仪式感、暗夜花园 | McQueen、中世纪教堂、黑玫瑰 |
| **现代极简** | 几何、克制、留白、结构、高级灰 | Celine、Jil Sander、建筑感 |
| **自然诗意** | 植物、生长、有机、流动、生命力 | William Morris、新艺术、田园 |
| **复古摩登** | Art Deco、几何、奢华、黄金时代 | 1920s、盖茨比、装饰艺术 |
| **解构重组** | 破碎、错位、拼接、不完整、实验性 | Margiela、川久保玲、解构主义 |

**输出**：3-5个情绪关键词 + 1-2个参考氛围（不是参考纹样，是参考感觉）

## 第二步：定义创新点

这是最核心的一步——**你的纹样创新在哪里？**

### 五种创新模式

| 创新模式 | 对应 innovation 模式编号 | 做法 | 举例 |
|---|---|---|---|
| **A. 骨格提取** | 模式 01 | 提取传统纹样的骨架，丢掉具象细节，变成纯几何/抽象 | 宋代折枝牡丹 → 提取"一枝一花+枝叶"的骨架，变成极简几何线条 |
| **B. 风格混搭** | 模式 02 | 把两种完全不同的风格元素，用同一个骨格串起来 | 宋式折枝 + 波普配色；波斯联珠 + 欧普视错觉 |
| **C. 解构重组** | 模式 03 | 把传统纹样打碎成零件，重新排列组合 | 缠枝莲拆成藤蔓+花瓣+叶子，打乱错位叠加 |
| **D. 材质转译** | 模式 04 | 把一种工艺的视觉语言，转成另一种工艺表现 | 刺绣的盘金骨架 → 数码印花的金色线条；蜡染冰裂纹 → 水洗做旧肌理 |
| **E. 古今对话** | 模式 05 | 同一个题材，古代画法 vs 现代演绎，做两层叠加 | 底层是宋式团花线稿，上层是现代抽象色块叠透 |

> **完整 15 种创新模式（含 06-15 新增）的操作步骤、案例、适用场景、难度与风险，见 `innovation-modes.md` 第一部分。**

**选择规则**：
- 建议至少选1种创新模式，不宜直接照搬传统
- 可以多种叠加（比如：骨格提取 + 风格混搭）
- 创新点越明确，设计越有灵魂

**输出**：明确说清楚——"我这个纹样的创新点是：XXX"

## 第三步：解构灵感原料

从各种来源里，提取可以用的**元素骨架**，不是直接照搬图案。

### 灵感原料来源
| 来源 | 提取什么 | 不要什么 |
|---|---|---|
| **传统纹样** | 骨格结构、构图逻辑、配色体系 | 具象细节、完整图案 |
| **自然形态** | 生长逻辑、有机曲线、疏密关系 | 写实的形状 |
| **艺术流派** | 色彩体系、构成方式、视觉语言 | 具体的画面内容 |
| **建筑/器物** | 结构逻辑、比例关系、装饰语言 | 具体的造型 |

**提取方法**：
1. 找到参考素材
2. 画它的**骨架线**（对称轴、重复单元、主结构线）
3. 总结它的**构图逻辑**（疏密、节奏、层次）
4. 丢掉具体的具象细节
5. 用提取的骨架，重新组合成新纹样

## 第四步：层次化构成设计

**高级感的常见来源：层次。** 不是一层纹样铺满，而是有多层结构。

### 常见的三层结构参考
| 层次 | 作用 | 密度 | 举例 |
|---|---|---|---|
| **底层（地纹）** | 营造氛围、增加质感 | 高密度、低对比 | 细密几何纹、肌理底纹、淡色暗纹 |
| **中层（主纹）** | 视觉主体、讲故事 | 中密度、中对比 | 主要花卉/几何/主题元素 |
| **顶层（点缀）** | 提亮、增加细节 | 低密度、高对比 | 金箔、珠点、小面积高饱和 |

### 层次设计的参考思路
1. **底层要"退"**：颜色淡、对比弱，不抢主纹的风头
2. **中层要"稳"**：主视觉，疏密有节奏
3. **顶层要"精"**：小面积，但有高光感

**注意**：三层结构是常见的高级感做法，但不是唯一的。根据主题和风格，可以做两层、四层，甚至更复杂的叠加。关键是**有层次，不平铺**。

**常见的反面情况**：
- ❌ 只有一层纹样，平铺直叙 → 容易显廉价
- ❌ 多层都一样密、一样艳 → 乱，没有焦点
- ❌ 全是细节，没有呼吸空间 → 闷

## 第五步：配色方案设计

配色没有标准答案，要根据主题、风格、情绪来定。以下是一些**常见的高级感方向**，供参考，不是必须遵守的法则。

### 常见的高级感配色方向

#### 方向1：低饱和 + 一个高亮点
- 主色调是灰调/低饱和（莫兰迪、灰蓝、灰粉）
- 小面积高饱和点缀（一点金、一点正红）
- 效果：整体柔和，但有视觉焦点
- 适合：东方雅致、极简、高级女装

#### 方向2：同色系深浅变化
- 同一个色相，从深到浅分层
- 底层最深，中层中等，顶层最浅或最亮
- 效果：统一、有层次、不杂乱
- 适合：单色系列、品牌统一感

#### 方向3：冷暖对比但面积悬殊
- 主色调约 70% 是冷色或暖色
- 剩余约 30% 是对比色点缀（与 `color-rules.md` 的冷暖 7:3 口径一致）
- 效果：有对比但不刺眼
- 适合：现代设计、品牌感

**注意**：以上是常见方向，不是公式。根据主题可以大胆打破——比如波普风就是高饱和撞色，暗黑风就是深色调，民族风就是浓郁色彩。关键是**配色要服务于主题，不要为了"高级"而高级**。

### 配色检查清单（参考）
- [ ] 有没有明确的主色调？（不宜五五开）
- [ ] 点缀色是不是小面积但有存在感？
- [ ] 去掉颜色只看黑白灰，构成是不是依然成立？
- [ ] 配色和主题/情绪是不是匹配？

## 第六步：工艺与肌理叠加

**高级感的常见来源：工艺层次。** 纯印花容易显平，有工艺层次会更有质感。

### 常见的工艺叠加方式
| 叠加方式 | 效果 | 适用场景 |
|---|---|---|
| **印花 + 局部刺绣** | 印底纹，绣主纹/点缀 | 高定、礼服、高端女装 |
| **提花 + 植绒/烫金** | 提花做底，局部植绒/烫金提亮 | 西装面料、高级礼服 |
| **肌理 + 印花叠加** | 面料本身有肌理（绗缝/抽褶），上面再印花 | 秋冬面料、层次感强 |
| **多工艺组合** | 印花+刺绣+烫金，多层叠加 | 顶级高定、重工礼服 |

### 工艺层次的参考思路
- **底层**：可以是印花/提花（大面积、成本相对低）
- **中层**：可以是印花/平绣（中等面积）
- **顶层**：可以是精致工艺（盘金/珠绣/烫金，小面积但贵）

**注意**：工艺叠加不是必须的。根据设计意图，可以纯印花（极简风）、纯刺绣（手工艺感）、纯提花（面料本身的质感）。关键是**工艺要服务于设计，不要为了"高级"而硬堆工艺**。

一个常见的思路是：越靠顶层的工艺，面积越小、越精致——这是"高级感"的成本逻辑，但不是唯一逻辑。

## 纹样命名规范

给纹样起专业名字，有固定格式：

### 命名公式
```
[创新点/风格] + [层次结构] + [主元素] + [纹样类型]
```

### 举例
| 名称 | 拆解 |
|---|---|
| 宋韵解构·缠枝莲锦地开光纹 | 宋韵解构（创新点）+ 锦地开光（层次结构）+ 缠枝莲（主元素）+ 纹 |
| 哥特卷草暗黑浪漫·三层叠加纹 | 哥特卷草暗黑浪漫（风格+情绪）+ 三层叠加（结构）+ 纹 |
| 现代极简·几何骨格提取纹 | 现代极简（风格）+ 几何骨格提取（创新点）+ 纹 |
| 波西米亚混搭·佩斯利底纹+花卉主纹 | 波西米亚混搭（创新点）+ 底纹+主纹（层次）+ 佩斯利+花卉（元素） |

### 命名规则
1. 前面放**创新点或情绪**（不是放"宋代"这种朝代名，而是放"宋韵解构"这种有设计思考的词）
2. 中间放**层次结构**（有几层、什么结构）
3. 最后放**主元素和纹样类型**
4. 听起来有设计感，不像商品名
