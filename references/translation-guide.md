## 四种转译模式

转译是把一种纹样转化成另一种风格/形式，是教学核心，也是设计常用方法。

### 模式一：骨架提取（抽象化）
**做法**：只提取纹样的骨式结构，丢掉具体细节，变成纯几何/抽象。

**例子**：
- 宋代折枝牡丹 → 提取"一枝一花+枝叶"的骨架，简化成极简几何线条
- 哥特卷草纹 → 提取涡卷曲线的节奏，变成抽象曲线纹样

**适用场景**：现代极简、解构主义、高端品牌

**输出要点**：
- 保留原骨式（对称/旋转/发射）
- 丢掉具象细节（花瓣、叶脉）
- 几何化、线条化
- 配色用低饱和、中性色

---

### 模式二：风格迁移
**做法**：保留纹样的构图和主体，换成另一种艺术风格。

**例子**：
- 宋代团花 → 波普风格（高饱和、平涂、硬边）
- 波斯联珠纹 → 欧普艺术（黑白视错觉、几何化）
- 缠枝莲 → 孟菲斯风格（撞色、几何化、playful）

**适用场景**：创意作业、年轻品牌、跨界设计

**输出要点**：
- 原构图不动
- 主体换成目标风格的表现手法
- 配色完全换成目标风格的经典配色

---

### 模式三：解构重组
**做法**：把纹样打碎成零件，重新组合成新的图案。

**例子**：
- 把缠枝莲拆成：藤蔓线条 + 莲花花瓣 + 叶子形状，打乱重新拼
- 把Art Deco几何拆成：阶梯形 + 放射线 + 圆形，错位叠加

**适用场景**：前卫设计、高定、Margiela式解构

**输出要点**：
- 保留原纹样的"零件"元素
- 打破原构图和秩序
- 错位、重叠、不对称
- 制造"似曾相识但又不一样"的感觉

---

### 模式四：材质转译
**做法**：把一种工艺的纹样，转成另一种工艺的表现。

**例子**：
- 刺绣纹样 → 数码印花效果（保留线条感，但变成平面）
- 织锦纹样 → 激光切割镂空（保留骨架，但变成透孔）
- 蜡染冰裂纹 → 做旧水洗肌理（保留随机纹理感）

**适用场景**：工艺创新、材料实验、高级定制

**输出要点**：
- 保留原纹样的核心特征（骨式/随机感/线条）
- 完全换一种材质表现
- 说明新工艺的适配性

## 古今对比方法

做课题、写论文时常用：同一个纹样题材，古代怎么画，现代品牌怎么用。

### 对比维度
1. **构图骨式**：古代是对称还是均衡？现代有没有打破对称？
2. **细节密度**：古代繁复还是简洁？现代是更简还是更繁？
3. **配色体系**：古代用什么色系？现代换成了什么？
4. **工艺适配**：古代是什么工艺？现代换成了什么工艺？
5. **文化寓意**：古代的寓意是什么？现代还保留吗？还是完全变成装饰？

### 对比输出模板
```
【题材】XX纹
【古代版本】（朝代+名称）
- 骨式：XXX
- 配色：XXX
- 工艺：XXX
- 寓意：XXX

【现代版本】（品牌+系列）
- 骨式：XXX（保留了什么，改变了什么）
- 配色：XXX（从什么色换成了什么色）
- 工艺：XXX（从什么工艺换成了什么工艺）
- 演变：XXX（从"有寓意的符号"变成"纯装饰"还是保留了寓意）
```

## 纹样演变线

梳理一个纹样从起源到现代的演变脉络，适合课题研究。

### 演变线维度
1. **起源期**：什么时候出现？最初是什么用途？
2. **发展期**：哪个朝代最盛？形态有什么变化？
3. **成熟期**：典型形制是什么？（代表作品）
4. **衰落期**：什么时候开始不走红？为什么？
5. **现代复兴**：哪个品牌/设计师重新用了？怎么改的？

**注意**：拿不准的史料标【待核实】，不要编造年代和出处。
