# AI 资产交付规范（asset-delivery）

> **重要前提**：本文件所有建议都是参考，不是硬标准。没有绝对的"高级/廉价"，也没有绝对的"对/错"——先想清楚你想要的是什么风格，再判断这些规则适不适用。

> 归属：pattern-texture-skill · 作用域：**pts 全部 AI 生成/编辑产物，无例外**——纹样图、肌理特写、配色色卡、四方连续拼接测试图、成衣效果等一切图片产物；不限于某一类纹样或某一种工艺。
> 前置：纹样设计流程走 `design-workflow.md`；出图提示词走 `prompt-templates.md`；翻车诊断走 `pattern-diagnosis.md`；版权合规走 `copyright-guide.md`。
> 版本：1.1.1 · 许可 CC BY 4.0

## 一、核心原则：两份即可，不自动保存

**默认规则（用户偏好）：pts 的每一张 AI 生成或编辑产物，只出现在两个地方——**

1. **对话展示一份**：在对话框用媒体卡片直接展示给用户（可见交付，必须做）。
2. **画布留一份**：由图像工具在生成时自动写入画布（若当前环境支持自动写入），Agent 不手动建条目。

**除此之外，Agent 不主动做任何保存动作**：不手动建画布条目、不做本地项目文件夹归档、不复制另存、不下载重传、不整理目录。用户觉得哪张好，自己保存；需要 Agent 额外归档时，用户会明确说。

> 判定：产物没在对话里直接展示，视为"未交付"；只给路径或文字描述不算交付。是否归档、存几份，不是交付的前置条件。

## 二、豆包办公默认实现（画布自动写入 + 对话框展示）

> 豆包办公的实现 = **一条原始产物短链，两处可见**：① 图像工具按 Workspace ID 自动写入画布（画布一份）→ ② 对话框媒体卡片展示（对话一份）。共用同一条工具返回值，不下载、不重传、不换链。

### 1. 画布自动写入（不手动建条目）
- 调用 `image_gen`／`image_edit` 时把当前对话的有效 `canvas_workspace_id` 作为参数传入；工具成功返回后，产物已自动写入画布（通常为 `gen-v2-*` 条目、`path="/"`），这就是"画布一份"。
- **禁止**再为该产物执行 `design-cli design-workspace +create`／`+create-batch`、`+get` 回读、`+update` 改 path、`FileBatchUpload`、下载、复制或另建 IMAGE Item——工具返回值里没有"已写入画布"的提示，容易误判为尚未落位而重复建条目，结果同一张图在画布出现两份。
- **宿主规则优先**：若当前环境（如画布规则）强制要求写入后 `+get` 核对，按宿主规则执行一次核对即可；核对只用于确认对象真实存在，不得据此再 `+create`、另存或另建条目。
- 判断画布中两条记录是否同一文件：比对条目 asset 的 `uri` 字段，`uri` 相同即同一份文件的两个条目。
- 定向 `+get` 可能因索引延迟返回空 items，此时用 `+tree`／`+ls` 或创建回执确认对象是否真实存在，不要据此判定写入失败而重复提交。

### 2. 对话展示（必须做）
- 主 Agent 把生成工具返回的**原始短链**通过媒体卡片（RichMediaCard；环境用 `present_files` 时同效）逐项展示，逐字使用工具返回值，不下载、不重传、不换链。
- 一次返回多张时按稳定顺序逐项展示，可分组（≤6 张/组）。用户"看到图"以此为准，不得只给路径或文字描述代替。

### 3. 不做本地归档
- 不主动把产物复制/另存到项目文件夹或本地素材库；这是用户自己的动作。用户明确要求本地存档时再做。

### 4. 绑定画布（仅初始化，不属于产物归档）
- 当前对话已有唯一有效 `canvas_workspace_id` 时直接复用；没有时调用 `design-cli design-workspace +workspace-create --title "<标题>"` 建一张，从响应 XML 读唯一 ID，并由主 Agent 用 `present_files(<workspace_id>)` 交付画布卡片（**不得**创建 workspace-id.txt 等中间文件）；画布卡片交付成功前不得生成/编辑媒体。
- `+get-workspace` 只用于显式查询、恢复或排障，不代替"对话无 ID 时必须创建"的初始化规则。

## 三、PTS 常见产物类型（仅说明，不要求自动归档）

> 纹样项目会产出以下几类图，它们的用途不同；是否留存、怎么命名由用户决定，Agent 不主动归档。

| 产物类型 | 用途 |
|---|---|
| 四方连续主图 | 纹样母版，后续衍生基于它 |
| 无缝拼接测试图 | 主图拼 3×3 看接缝，验证能不能用 |
| 配色色卡图 | 主色/辅助/点缀色，方便后续打样 |
| 面料肌理特写 | 微距看织纹/光泽/凹凸，用于工艺参考 |
| 成衣效果参考 | 纹样上身后的比例与密度 |
| 工艺方案图 | 印花/刺绣/提花等不同工艺效果对比 |

> 用户要求归档时，可参照上表分类；默认只在对话展示、画布自动留一份。

## 四、出图模型选择（默认平台）

> 详见 SKILL.md「生成工具与入口」。本节只列纹样场景的特殊判断：

| 场景 | 推荐模型 | 为什么 |
|---|---|---|
| 四方连续纹样（高精度） | Seedream 5.0 Pro | 无缝拼接的边缘细节很重要，Pro 精度更高 |
| 面料肌理特写（微距） | Seedream 5.0 Pro | 织纹/光泽/凹凸的细节是核心，不能糊 |
| 配色方案预览 | 5.0 Flash / 标准版 | 快速看配色方向，不用高精度 |
| 成衣效果参考 | Seedream 5.0 Pro | 服装版型 + 纹样位置 + 面料质感，综合度高 |
| 草稿/快速迭代 | 5.0 Flash / 标准版 | 省时间，快速看大方向 |

## 五、其他环境降级（工具中立）

- **无自动画布写入 / 无 design-cli 环境**：对话媒体卡片展示不变；是否需要手动写入画布或归档，按用户的明确要求执行，不擅自增加步骤。
- 换 Agent / 平台时按各自能力映射做对应调整；任何环境下"对话直接展示"都是底线，自动归档不是。
