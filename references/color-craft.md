## 四、不同工艺的配色限制

颜色在屏幕上是 RGB，到了面料上要过工艺这一关。**同一个 HEX 色值，丝网印印不出来的、刺绣打不到的、提花织不出的，都不一样**。下面是每种工艺的硬限制和避坑点。

### 4.1 丝网印（Screen Printing）

| 项目 | 限制 |
|---|---|
| **色数** | 一套版 4–8 色最经济；超过 12 色成本飙升。每多一色加一套版、一次刮印 |
| **渐变** | 只能靠"网点疏密"模拟渐变（半色调），做不出平滑过渡。最小网点 30–50 线/英寸，太细会堵网 |
| **套色精度** | 存在 ±0.2–0.5mm 量级的误差；过细的线条和精细对版会糊 |
| **显色特点** | 色块平、饱和度高、边缘锐利。适合色块分明的纹样，不适合水彩晕染感 |

**配色建议**：
- 色数控制在 **4–6 色**，每个色都是明确色块。
- 不建议在设计稿里做 8 个以上的渐变色阶——要么改成分层色块，要么换数码印。
- 深色面料上印浅色 → 必须先打白底（underbase），否则透底发灰。
- **避坑**：相邻两色如果太接近（明度差 <1.5 级），丝网印出来会糊成一团，因为套色精度不够。

### 4.2 数码印（Digital Print）

| 项目 | 限制 |
|---|---|
| **色数** | 无限制（CMYK + 专色），理论上千万色 |
| **渐变** | 平滑渐变、晕染、水彩感都能做 |
| **成本** | 不随色数线性增加（按米数收费），但打样贵、大货单价高于丝网 |
| **显色特点** | 颜色偏柔、饱和度比设计稿低 10–20%。深色在浅色底上容易"渗" |

**配色建议**：
- 数码印是**唯一能跑高复杂度、多色渐变的量产工艺**。8 色以上、有渐变、有晕染的纹样，直接上数码印。
- 设计稿要把颜色**打样后校色**——屏幕上的高饱和色印出来会灰一档，所以设计时纯度可以比预期高 1 级。
- **避坑**：数码印在深色底上印浅色（尤其荧光色）容易发灰，因为墨水是"染"不是"盖"。深底浅色纹样建议选浅色面料 + 深色印花，而不是反过来。

### 4.3 刺绣（Embroidery）

| 项目 | 限制 |
|---|---|
| **线色数量** | 一件作品常用 10–20 个线色；高端苏绣可达 50+ 色线号 |
| **渐变** | 靠**相邻色号过渡**实现（如从大红 → 朱红 → 橘红 → 橙，每 1–2mm 换一个线号），不能无缝渐变 |
| **线色体系** | 用 DMC / 苏绣线号，不是 HEX。设计师要按线号选色 |
| **显色特点** | 线有光泽，同个色号在不同针向下反光不同 → 有立体色彩感 |

**配色建议**：
- 刺绣配色的核心是**线号阶梯**：一个主色（如红花）要备 3–5 个邻近线号做渐变（深、中、浅、高光）。
- **金属线**（金线、银线）在刺绣里比印花里更出彩——因为有真实金属反光。但金属线面积建议不超过 10%，否则俗气。
- **避坑**：
  - 不建议指望刺绣做"平涂大色块"——大面积平绣会起皱、成本极高。大色块用针脚密的缎面绣，或改用印花。
  - 线色比色卡看起来深半档（线是立体的、有反光），选线号时比预期浅半档。

### 4.4 提花 / 织锦（Jacquard / Brocade）

| 项目 | 限制 |
|---|---|
| **纬纱数** | 经典宋锦 2–4 枚纬、云锦 8–16 枚纬、现代提花可达 24+ 色同时织入 |
| **配色逻辑** | 颜色由经纬纱交织决定，**不是"印上去"，是"织出来"**。同个颜色在不同织法下显色不同 |
| **渐变** | 极难做平滑渐变，只能靠不同色纱的小段拼接（"换道"） |
| **显色特点** | 颜色温润、有织物肌理感、不刺眼。提花色天然比印花色"灰半档" |

**配色建议**：
- 提花纹样配色要**克制**：一枚纬一个色，色数 = 纬纱数。3–5 色的提花最经典（宋锦、宋式纱）。
- 想要"华贵感"→ 加一枚金线纬（织入少量金），立刻从"布"变"锦"。
- **避坑**：
  - 提花不建议追求"像印花那样的丰富色"——颜色多了纬纱成本指数上升，而且织出来会脏。
  - 提花的色彩对比要靠**明度差**，不建议靠色相差。因为纱线本身的纯度被织物结构"压灰"了。

### 4.5 手绘 / 扎染 / 蜡染（Hand-dyed / Tie-dye / Batik）

| 项目 | 限制 |
|---|---|
| **色数** | 手绘 5–10 色；扎染/蜡染 2–5 色最自然 |
| **渐变** | 天然擅长——渗色、晕染、随机边界就是它的美学 |
| **可控性** | 低。每次扎染结果都不一样，不能 100% 复现 |
| **显色特点** | 颜色通透、有手工感、边缘不规则 |

**配色建议**：
- 扎染/蜡染要**利用渗色**，不建议和它对抗。设计时把"边界模糊"当成美学特征，不建议画清晰色块。
- 配色建议**同色系晕染**（藏蓝 → 浅蓝 → 白；砖红 → 橘 → 米），跨色系容易脏。
- **避坑**：
  - 扎染不建议用超过 4 个色——多色扎染极容易脏成"咸菜色"。
  - 蜡染的蜡裂产生的冰纹是天然点缀，不建议额外加印白点。

### 4.6 工艺配色速查

| 工艺 | 推荐色数 | 渐变能力 | 显色特点 | 最适合的配色类型 |
|---|---|---|---|---|
| 丝网印 | 4–6 | 弱（半色调） | 平、艳、锐利 | 色块分明、波普、几何 |
| 数码印 | 不限 | 强 | 柔、灰半档 | 复杂纹样、水彩感、多色 |
| 刺绣 | 10–20 线号 | 中（线号过渡） | 有光泽、立体 | 重工、花卉、金属点缀 |
| 提花 | 3–8 纬 | 弱 | 温润、灰半档 | 经典锦地、宋式、低对比 |
| 扎染/蜡染 | 2–5 | 极强（天然渗色） | 通透、不规则 | 同色系晕染、波西米亚 |

## 五、配色的视觉修正

屏幕上看着对的颜色，上了面料常常不对。这一节讲"预判 + 修正"。

### 5.1 面料材质对色彩的影响

| 面料 | 显色特点 | 配色修正 |
|---|---|---|
| **纯棉** | 吸色，颜色比设计稿深半档、灰半档。哑光 | 设计稿纯度加 1 级、明度加 0.5 级 |
| **丝绸/缎面** | 反光强，深色显深邃、浅色显通透。同个色不同角度有色差 | 不建议用太花的多色（反光会让颜色"跳"），用 2–3 色干净配色 |
| **亚麻/麻** | 粗糙，颜色吃进纤维里，偏灰、偏哑 | 可以用稍微艳一点的色（被麻面压灰后刚好） |
| **雪纺/乔其** | 半透明，颜色叠色处会变深 | 设计时把叠色位置预留出预期叠色，不建议靠叠色出新色 |
| **针织/毛圈** | 蓬松，颜色显得"浮"，边界不清 | 主纹明度差要拉大到 3.5 级以上，否则糊 |
| **黑色针织** | 吸色最狠，任何色上去都暗一档 | 印浅色必须打白底；刺绣线选亮半号 |

### 5.2 深浅面料上的颜色调整

**深色面料上想印/绣浅色**：
- 屏幕上看着"奶白"的色，印到黑布上会变"灰粉"。
- 修正：浅色色号选比预期**亮 1–1.5 级**的（如要奶白就选米白偏白 1 档）。
- 刺绣：深面料上绣浅色线，选线号时**选比预期浅半号到一号**。
- 不建议在黑布上直接印荧光色——透底后是脏荧光。

**浅色面料上想加深色**：
- 屏幕上看着"藏青"，印到白布上可能变成"钴蓝"（浅底显色艳）。
- 修正：深色色号选比预期**深半档**（如要藏青就选海军蓝偏深 0.5 级）。
- 刺绣：浅底上绣深色线，选线号时**选比预期深半号**。

### 5.3 纹样大小对色彩感知的影响

同样的颜色组合，放大纹样和缩小纹样，看起来像两套配色。

| 纹样尺度 | 视觉特点 | 配色修正 |
|---|---|---|
| **大纹样**（单元 > 10cm） | 能看清每个颜色的细节、渐变、层次 | 可以用 4–6 色，色相差可以大，细节层次重要 |
| **中纹样**（单元 3–10cm） | 远看是花型，近看是色 | 用 3–5 色，明度差 2.5–3.5 级最舒服 |
| **小碎花**（单元 < 3cm） | 远看是"一块色面"，近看才是花 | **色数压到 2–3 色**，色相差要小（同类／邻近，≤30°），否则远看是"脏点子"。小碎花最忌多色——3 色以上远看就是灰糊糊一团 |
| **极小花纹**（< 1cm，如锦地纹） | 几乎看不出具体色，只贡献"整体色调" | 用同色系深浅差 1–2 级即可，不建议跳色 |

**判断规则**：
- 小碎花配色的检验方法：把纹样缩略到 1cm 远看——如果整体不是一个干净的色调，而是"五颜六色的脏点"，就要减色。
- 大纹样可以做"局部小点缀高饱和"（如大花里一点亮黄花蕊），小碎花不行——小碎花里的高饱和点远看是噪点。

### 5.4 连续纹样重复后的整体色感

四方连续贴在 A4 上看是一套色，贴在一米宽的衣服上是另一套色。原因：

1. **重复密度效应**：同一个色重复 50 次后，视觉占比会被放大。设计稿里主纹占 20%，满铺到衣服上看起来像 35%。
2. **色彩同时对比放大**：相邻重复单元互相衬托，补色对比会被放大 1.5 倍。
3. **距离效应**：人站在 1 米外看衣服，只能看清大色面，看不清小细节。

**预判方法**：
- 设计时把四方连续单元**复制 4×4 或 6×6 排满一整屏**看整体，不建议只看一个单元。
- 把整屏缩略到 **5cm 见方**远看——这是人穿在身上别人看到的距离。如果缩略后整体色调干净统一，配色就对了；如果缩略后是"花糊糊"，就要减色或拉大明度差。
- 主色面积在连续满铺后会膨胀 1.3–1.5 倍。设计时主纹占比压到 15–20%，满铺后看起来才是 25–30% 的舒适比例。

### 5.5 预判清单

打样前用这张表自查：

- [ ] 纹样在目标面料上打印过小样吗？（纯棉 vs 丝绸显色差半档以上）
- [ ] 四方连续 4×4 排满后远看（5cm 缩略）色调统一吗？
- [ ] 深底上的浅色是否加了白底/选亮了一号？
- [ ] 浅底上的深色是否选深了半号？
- [ ] 小碎花（<3cm）的色数是否压到 3 个以内？
- [ ] 补色面积是否悬殊（>85:15）？
- [ ] 点缀色总面积是否 <8%？
