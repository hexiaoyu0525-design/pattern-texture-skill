## 五种出图场景模板

### 场景一：单独纹样（白底，方便提取）

**用途**：设计一个单独的装饰纹样，白底方便后期抠图用在衣服上。

**提示词模板**：
```
单独纹样设计，[风格标签]风格，[骨格]构图，[主体元素]，
[配色方案：主色+辅助色+点缀色]，
线条清晰，轮廓明确，[细节描述：如"缠枝藤蔓环绕花卉"]，
高质量纹样设计，矢量风格，干净简洁，
纯白背景，居中构图，纹样周围留适当留白
```

**负面提示词（建议加）**：
```
photorealistic, photo, realistic texture, 3d render,
cluttered background, multiple patterns, off-center,
blurry, low quality, distorted
```

**参数建议**：
- 比例：1:1
- 风格强度：中等（不要太艺术，要清晰）
- 细节强度：中高（纹样要精致）

### 场景二：四方连续（满铺，无缝拼接）

**用途**：生成满铺面料印花，要求无缝拼接。

**提示词模板**：
```
四方连续纹样图案，[风格标签]风格，[骨格]骨格，
[组织形式：如"散点式" / "连缀式" / "锦地开光式"]，
[主体元素：如"折枝花卉" / "几何纹" / "缠枝纹"]，
[配色方案]，
无缝拼接图案，tile pattern，repeat pattern，
满铺效果，纹样均匀分布，疏密有致，
平面印花风格，清晰轮廓，[复杂度：如"中等复杂度"]，
[去AI塑料感：如"细节有自然变化，手工感，非机器完美"]
```

**负面提示词（建议加）**：
```
seam visible, broken pattern, uneven distribution,
clustered, too dense, too sparse,
photorealistic, 3d, shading, depth,
blurry, low quality
```

**参数建议**：
- 比例：1:1（方便看拼接效果）
- 风格强度：中等
- 细节强度：中高

**关键约束**：
- 必须强调 "seamless tile pattern"、"repeat pattern"
- 建议避免明显边界感
- 建议避免太大空白或太密集区域

### 场景三：面料肌理特写（材质感，微距）

**用途**：生成面料肌理的特写图，看材质效果。

**提示词模板**：
```
[肌理类型，如"提花面料" / "绗缝肌理" / "扎染棉布"]面料特写，
微距镜头，面料纹理细节，[材质特征：如"有凹凸感" / "光泽感" / "透孔感"]，
[颜色：如"深藏蓝色" / "米白色"]，
真实面料质感，自然纹理，
[去AI塑料感：如"手工感，自然随机，非完美均匀"]，
8K高清细节，微距摄影，面料平铺
```

**负面提示词（建议加）**：
```
printed pattern, graphic design, flat illustration,
digital art, plastic texture, artificial,
perfectly uniform, synthetic, fake fabric,
blurry, low quality
```

**参数建议**：
- 比例：1:1 或 4:3
- 风格强度：低（要真实，不要太艺术）
- 细节强度：极高（肌理要清晰）

**关键约束**：
- 必须强调 "fabric texture"、"macro shot"、"realistic fabric"
- 不能有"图案感"，要是"材质感"

### 场景五：线稿图（黑白线描，方便画草图）

**定位**：线稿是纹样的**第一阶段（链路第 0 步）**，不是"随便出张草稿"。它把骨格、三格、线型、单位密度一次性锁死，之后的上色、载体降维、展示视频都以它为锚点。分三种情形：从零生成（A）、把已有成品反推成线稿（B）、线稿转上色（C）。

**什么时候可以不走线稿**：① 只想快速看效果、单张试配色——即使还没有纹样，也可以直接出彩色图；② 已有可用成品，且不需要严格拼缝、不做系列一致性、不给载体与视频当锚点。**什么时候该走线稿**：要系列、要拼接、要上色锁结构、要当锚点——没有纹样走情形 A，已有成品走情形 B 反推。

### 两条铁律（先看这两条，再挑情形）

1. **"闭合完整"排第一，它是线稿的准入条件。** 每条线必须首尾相接、轮廓闭合、无断口、无开口。断一处，上色时就会漏填、颜色从缺口漫出边界；更麻烦的是断口在缩略预览里看不出来，往往等做到实物图或放大看才发现，前面全部返工。
   - **验收三步**：放大到线条交汇处，逐个找 ① 断口　② "看似连上、其实断开"的细缝　③ 轮廓没有收口的开口线。任何一处出现，先修线，不进入上色。
2. **线稿阶段只允许黑白或单色。** 一旦在这一步让它上色，下一步就失去可控性——颜色由模型替你决定，之后再想锁结构、锁配色，只能整张重跑。线稿的价值在于"把结构定死"，不是"先随便出一版彩色再改"。

> 这两条同时约束**情形 A/B**（出线稿）与**情形 C**（线稿转上色）：上色开始之前，线稿必须是单色且闭合的。

### 线稿前先定骨格与组织形式（跳过这步，AI 会替你随机排）

出线稿之前必须先定三件事，否则提示词里的 `[骨格]` 只是空话：

1. **组织形式**：单独纹样 / 适合纹样（随圆形·方形·菱形·扇形外轮廓变形）/ 连续纹样（二方连续为一维重复，四方连续为满铺）。
2. **骨格**：决定纹样沿什么路径重复。只写"四方连续"、不写骨格，同一主题多张图的排法会各不相同，系列图无法复现。
3. **单位与连接**：单位纹样由哪些元素构成、连接点在哪、四边（或两端）如何对接。

**骨格 → 提示词关键词对照（直接抄进 `[骨格]` 位置）**

| 骨格 | 提示词写法 | 视觉后果与适用 |
|---|---|---|
| 散点式（二方/四方） | `散点式四方连续，单位互不连接、均匀分布` | 简洁、主纹突出，但易呆板；适合印花满铺、边饰 |
| 波线式 | `波线式二方连续，波状曲线为骨格` | 流畅连绵；卷草、衣缘、门框类边饰首选 |
| 折线式 | `折线式二方连续，折线骨格转折连接` | 刚劲跳跃；几何/民族风边饰 |
| 直立式 | `直立式二方连续，单位直立反复` | 方向明确、整齐；上下向饰带 |
| 连锁式（连环式） | `连锁式二方连续，几何形相互套接` | 环环相套、连续性强；纹样带 |
| 开光式 | `开光式二方连续，几何开光内配置主纹` | 主体突出；织锦、地毯边、包装 |
| 连缀式（菱形/接圆/几何/缠枝） | `连缀式四方连续，菱形骨架贯穿相连` | 骨架线相连、连绵不断；锦地、丝巾主纹 |
| 重叠式（浮纹+地纹） | `重叠式四方连续，浮纹为主、地纹简洁作底` | 双层层次、华丽；高密度织物 |

**排列三格（只写骨格类名还不够）**

骨格定的是"哪一类重复"，排法还差三个数：

| 格子 | 写什么 | 常见取值 |
|---|---|---|
| **骨格点** | 节点按什么轨迹分布、每点放什么 | 4×3 方格等距 / 斜向点阵（横向 1 单位、纵向 0.5 单位）/ 主次双点阵 |
| **错位量** | 相邻行错开多少（只在一个方向错） | 平排 0 / 半错位 1/2 / 阶梯 1/3 / 深错接 2/5 |
| **环绕方式** | 围绕中心几层、怎么指（单独/适合纹样用） | 单环朝心 5 个 / 双环逆向 / 顺向旋转 |

> 三格的取值与视觉后果见 `composition-basics.md` 1.5（骨格点、错位量三档）与 `composition-expression.md` 6.1（环绕四参数）。只写"错位""环绕"，模型会自己随机选，系列图就散了。

**结构闭合：闭合完整不只是"线不断"**

| 层级 | 要求 | 只在第一层过关的后果 |
|---|---|---|
| 线条闭合 | 每条线首尾相接、无断口、无开口 | —— |
| 单位闭合 | 一个单位纹样本身完整，不残在半路 | 上色后出现半朵花、半个图形 |
| 接缝闭合 | 四方连续四个对边、二方连续两个接头能对上；接缝处纹样要么完整穿过、要么对称断开 | 单看每张都没问题，一拼就散、接缝处半截断 |

> 三层都验收过，线稿才算可交付。只做第一层，缩略图好看，放大或拼接即崩。

> 骨格的几何原理、散点疏密、连缀串法、重叠对齐与拼接错误类型，见 `composition-basics.md` 第 1.5 节（骨格点 / 错位量三档）、第 1.6 节（骨格选择速查表）、`composition-structure.md` 第 2.2–2.5 节；不要在提示词模板里重复推导。

> 线型怎么选（十八描三分法与主题匹配）、单位纹样的主次与密度预算、定稿拼缝检验（4×4 拼接 / 灰度 / 缩略），见 `lineart-method.md`。场景五只给模板，方法论不在本文件复述。

```

[骨格点：如"4×3 方格等距点阵"/"斜向点阵，横向1单位、纵向0.5单位"/"主次双点阵，小点填隙"]，
```

**情形 B：从彩色成品重绘线稿（建议分两遍，不要指望一次到位）**

当线稿要和某张彩色成品严格对应，或线稿老是发灰发淡时，按两遍走：

- 第一遍（对齐结构）：以彩色成品为唯一结构基准，在提示词里逐项点明要对应的元素（中心主纹、四周每个小团纹各是什么、地纹网格、角花、外框、最外白框），要求位置、大小、数量一一对应、不增不减，先保证结构对齐。
- 第二遍（两值锐化）：以第一遍结果为基准、只改清晰度，显式声明只用纯黑与纯白两个值：`two-tone pure black and white, only solid black lines on pure white background, no grayscale, no light gray, no semi-transparent, no blurry lines`；保留粗/中/细三层粗细分工——主纹轮廓粗线、团珠网格云纹中线、最密地纹细线，但细线也必须是纯黑实线。

> 实测要点：只写"线条清晰、纯黑、无灰阶"，模型仍容易输出整体偏灰、细线过淡的线稿；显式写出 `two-tone pure black and white` 能明显压灰，但**不等于纯两值**——实测灰阶像素占比 8.7% 只降到 7.4%，抗锯齿边缘仍在。要真正的两值稿，得自己做阈值二值化或矢量重描；这句话的价值是"让线变实"，不是"让图变成两色"。

**负面提示词（建议加，情形 A/B 用）**：
```
color, shading, grayscale, painted,
photorealistic, 3d, texture,
blurry, thick lines, messy,
colored pencil, watercolor,
light gray, faint lines, washed out,
broken lines, open contours, unclosed outlines, gaps in lines, missing segments,
single uniform line weight, flat line hierarchy, no width variation
```

> 最后一行专治断线：`broken lines / open contours / unclosed outlines` 比只写"线条清晰"有效得多。
>
> 英文组用于英文模型或英文平台；中文模型直接用文末「负面提示词库」里的中文条目，语义对等，不必硬翻。

**参数建议（情形 A/B）**：
- 比例：1:1（从彩色成品重绘时沿用原图比例）
- 风格强度：低
- 细节强度：中等

### 情形 C：线稿 → 上色（结构锁定，线稿要继续做上色时用）

情形 A/B 只解决"线在不在"，不解决"上色时结构会不会跑"。从线稿往下上色时，必须把线稿当**结构基准**，而不是当"风格参考"或"灵感图"。

**提示词模板**：

```
以原始"[纹样名称]"[线稿形态]为基础进行精细上色，
严格保留原有构图、[主体]造型、[辅助元素]、[中心结构]、四角装饰与外框几何纹样，
不改变任何线稿结构和纹样位置；
整体采用[配色体系]色体系，以[色卡：5–8 色]为主色，同一纹样内部通过不同色块分层，
所有轮廓与分色边界以[描边色]强化装饰感；
[质感约束句]，色彩[色彩调性]，呈现[整体调性]效果。
```

**两条写法差异（决定成败）**：

1. **"严格保留原有构图……不改变任何线稿结构和纹样位置"不能省**。这是上色阶段唯一的防漂移锚点；删掉后，模型会把线稿当参考图"重新画一遍"，结构必然微调。
2. **质感约束句要和所选质感匹配**。做平涂矢量 → 写"无渐变、无真实光影、无立体体积、无材质纹理"；做绢本/水彩/矿物厚涂 → 改成"保留笔触与颗粒层次、单层柔光、无强反光"。两条矛盾指令同时存在，会把画面拖成发灰的糊图。

**五条注意**：

- **上色前先验线**：放大检查线稿是否闭合。发现断口就回情形 A/B 补线，不要用上色去"盖"缺口——缺口盖不住，只会在色块之间留白缝，或让颜色漫出边界。
- **上色前还要验骨格**：核对排法与设定骨格是否一致——散点式不该冒出连接线，连缀式不该断开骨架，四方连续的四边接缝要对得上。不一致就回情形 A 重跑，不要指望靠上色阶段改排法；上色只会把错误的排法固定下来。
- 参考图权重调到偏高档（多数平台对应 0.7–0.9 区间，属经验值，按各平台刻度换算）。权重不足时线稿会被当灵感而不是骨架；调到高档仍漂移，先按情形 B 两遍法把线稿重做干净，再回来上色。
- 色卡给**颜色名**，5–8 个为止；超过 8 个，模型会自己编第 9、10 个。
- 平台不支持图生图时，这一步必然改形，改用局部重绘或分区块上色，不要用文生图硬跑。

> 实测要点：这条链在丝巾主题上完整跑通过（线稿 → 矿物色平涂 → 产品静物 → 展示视频），全程纹样结构未变；其中"严格保留原有构图"一句是效果差异最大的部分。

**负面提示词（情形 C 用，与 A/B 相反——上色要的是有颜色、线条退为轮廓）**：
```
grayscale, faint lines, line art only, blank areas, color bleeding outside lines,
pattern distortion, redrawn pattern, gradient, heavy shadow, 3d render,
pattern rearrangement, inconsistent repeat, broken repeat junction, half pattern at edges,
plastic texture, extra text, watermark
```

**参数建议（情形 C）**：
- 比例：沿用线稿比例
- 风格强度：低（要忠实搬运，不要二次创作）
- 细节强度：中高（色块分界与描边要清晰）

## 负面提示词库（带风格前提）

> **重要**：负面提示词不是所有场景都必加，要根据你想要的风格调整。下面标注了哪些是"所有场景都加"，哪些是"默认加，但某些风格可以去掉"。

### 基础负面提示词（所有场景建议加）
```
low quality, blurry, distorted, watermark, text, signature,
ugly, unattractive, poorly designed
```

### 纹样专用负面提示词（默认加，部分可按风格去掉）
```
generic pattern, boring design, cliché,
flat, lifeless, no depth
```
- `overly detailed, cluttered, messy composition` → **默认加，但满密繁复风格（云锦/巴洛克/伊斯兰纹样）可以去掉**
- `digital art, illustration style` → 想要真实感时加，想要插画风格时不加

### 去AI塑料感专用负面提示词（默认加，精确几何风格可去掉）
```
plastic texture, synthetic, artificial,
digital painting smoothness, CGI look,
generic AI pattern, cookie cutter design
```
- `overly smooth, too clean, machine-perfect` → **默认加，但精确几何风格（包豪斯/波普/工业风）可以去掉**

**关键原则**：去AI味 = 细节的手工感，不是破坏整体构成。
- ✅ 正确做法：花瓣形状有轻微差异、线条有自然不均匀、颜色有细微深浅变化
- ❌ 错误做法：整体对称被打破、重复单元大小不一、构图歪斜（这会把纹样本身搞坏）

**注意**：纹样本身就是靠规整构成的（四方连续要重复、团花要对称、二方连续要均匀），这些**建议不放进负面提示词**。去AI味是体现在**细节的手工感**上，不是破坏整体构成。

### 面料肌理专用负面提示词
```
printed pattern, graphic, flat design,
fake fabric, artificial texture,
3d render, cgi, plastic
```
- `too uniform, synthetic looking` → **默认加，但想要均匀平整的面料（比如缎面）可以去掉**

### 产品静物与服饰品载体（完整词表见 `product-prompts.md`）

```
person, model, human, hand holding, portrait, face,
cluttered background, warped pattern, redrawn pattern,
shiny plastic texture, extra text, watermark, wrong proportion
```

- 一律**无人物**：服饰品用无人台/平铺/微距。
- 负面词与正向的"纹样完整不变形、图案不重绘"要成对写，单写一边都不稳。

### 成品展示视频（完整词表见 `showcase-video.md`）

```
pattern distortion, redrawn pattern, border misaligned, exaggerated fabric flapping,
cheap plastic light, over-glow, particles, flicker, ghosting, clipping, subject drift, human figure
```

- 视频负面词 8–12 个足够，堆太多会削弱正向描述权重。
