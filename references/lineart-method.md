# 线稿方法论：线型 / 单位 / 接缝

> 本文补 `prompt-scenes.md` 场景五的三块空白：**线怎么写**（线型语言）、**单位怎么定**（主次与密度预算）、**怎么验**（拼缝检验）。三块都能脱离 AI 单独使用，作为人工验收标准。
>
> 判断口径统一为**画面效果**，不涉成品尺寸、工艺参数与打样——那是版师、刀版与工厂的事。

---

## 1. 线型语言：线不是轮廓，是风格

线稿最容易犯的错，是把"线"当成描边工具。线型本身承载风格：同一主题换一种线，风格就变一次。只写"线条流畅"，模型会退回默认的均匀细线，于是十个不同主题的线稿长得像同一张。

### 1.1 三类线型（据白描"十八描"三分法）

| 类别 | 线型 | 笔迹特征 | 适合的纹样主题 | 提示词写法 |
|---|---|---|---|---|
| **无粗细变化** | 游丝描 | 细而匀、圆转、顿笔小圆头 | 花卉、绢本、敦煌飘带 | `游丝描式细匀圆转，线条等宽无粗细变化` |
| | 琴弦描 | 略粗、多直线、有停顿 | 器物、织带、建筑构件 | `琴弦描式，近乎等宽直线，行笔有停顿` |
| | 铁线描 | 方硬转折、直线硬折、似铁丝 | 青铜、几何、器物、硬质材料 | `铁线描式方硬折角，线条等宽、转折见棱` |
| | 行云流水描 | 软而弯转、连绵 | 云气、水波、飘带 | `行云流水描式，软而连绵的等宽曲线` |
| | 曹衣描 | 细而下垂、圆弧、重疏密排列 | 垂坠织物、衣纹、垂帘 | `曹衣描式，细线圆弧下垂，线条排列疏密有序` |
| **有粗细变化** | 兰叶描 | 中间粗、两头细 | 卷草、藤蔓、花卉枝叶 | `兰叶描式，中间粗两头细，起收渐细` |
| | 柳叶描 | 两头细、虚入虚出 | 轻盈花叶、飞鸟 | `柳叶描式，虚入虚出、两端渐细` |
| | 钉头鼠尾描 | 起笔顿头重、收笔尖细 | 写意花鸟、刺绣底稿 | `钉头鼠尾描式，起笔重顿、收笔尖细` |
| | 蚯蚓描 | 匀而曲折柔软 | 缠枝、柔软藤条 | `蚯蚓描式，粗细均匀但转折柔软多曲` |
| | 战笔水纹描 | 颤动、水波感 | 水纹、褶皱织物 | `战笔水纹描式，线条微颤如水纹` |
| **减笔类** | 撅头钉描 / 折芦描 | 秃笔方顿、粗线直角折 | 剪纸、民俗、版画感 | `减笔描式，粗线方顿、直角折，一笔成形` |
| | 竹叶描 / 枯柴描 | 中粗两头细 / 干涩苍劲 | 粗犷民俗、木刻感 | `枯柴描式，粗涩线条，有干笔感` |

### 1.2 三条硬规则

1. **一幅线稿只用一类线型。** 混用两类以上，风格会分裂；需要层次靠线宽拉开，不靠换线型。
2. **三级线宽必须一眼可分。** 主轮廓最粗、内部结构线中等、地纹与细节最细。比例不必量化，但三级在缩略图里也要能分辨——分不出，上色时就没有可依据的色块边界。
3. **主题与线型要匹配。** 线的视觉心理是明确的：直线带速度感、锐利、阳刚；曲线带柔美、流动、弹性。所以几何、青铜、器物走直线系（铁线、琴弦、折芦），花卉、云水、卷草走曲线系（游丝、兰叶、行云流水）。**主题与线型错配，结构再准也不像那件东西。**

### 1.3 四种常见错配

| 主题 | 常错线型 | 出来的效果 | 改法 |
|---|---|---|---|
| 青铜 / 几何 / 器物 | 游丝式细匀线 | 软塌、失重 | 铁线描式，方硬转折 |
| 花卉 / 卷草 / 云水 | 铁线式硬折 | 生硬，像机械零件 | 兰叶描 / 游丝描 |
| 剪纸 / 民俗 / 木刻 | 兰叶式渐变线 | 失去刀味 | 减笔 / 折芦，粗线等宽 |
| 刺绣底稿 | 全图同粗 | 无法分层上色 | 三级线宽 |

## 2. 单位纹样：主次、比例、密度预算

线稿阶段真正被忽略的，是"一个单位里放了多少东西"。这个信息量一超，后面载体降维必糊；这一步一旦做对，后面省事。

### 2.1 一个单位只允许一个视觉中心

- 主纹 **1 组**，最多 2 组且必须有明显强弱；两组同强的结果是"没有重点"。
- 主纹刻画细、次纹概括——这是图案造型的基本法则：**加强主要部分，减弱次要部分**。落到线稿上就是细节预算分配：主纹可以三级线宽全用，次纹只给 1–2 级。全域同密度，上色后一定是平的。

### 2.2 面积与比例

- 主纹占单位面积约 **1/3–1/2**（视觉经验口径）。低于 1/3 显得空，高于 1/2 压迫留白。
- **避免均分**（一半对一半）：视觉会停在分割线上，拼接后形成等距网格。
- 元素数量取 **奇数**（3 / 5 / 7）。偶数容易均分，画面呆板。

### 2.3 水路均匀（留白纪律）

- 单位内白地与纹样要均匀穿插，不能一侧挤死、一侧大片空。
- 检查法：眯眼看单位，白地应呈**若干大小相近的水路**，而不是"一团大空 + 一堆密纹"。
- 这条直接决定拼接后会不会出现"密度河流"（见 3.4）。留白不均，单看没事，铺开成条带。

### 2.4 信息密度分档（视觉经验值）

| 载体视觉尺寸 | 单位内细节层级 | 理由 |
|---|---|---|
| 大件（整幅丝巾、挂毯、大幅包装） | 3 级（主轮廓 + 结构线 + 细纹） | 有面积承载细纹 |
| 中件（抱枕、包袋、礼盒面） | 2 级 | 缩小后细纹并成灰面 |
| 小件（冰箱贴、首饰、胸针） | 1–2 级，只留剪影与主轮廓 | 低于视觉分辨，细纹全糊 |

> 口径是屏幕或印前预览的视觉尺寸；实际成品尺寸与降维换算走 `carrier-guide.md`。

## 3. 拼缝检验：三个动作，肉眼看不出来

单张检查永远代替不了拼接检查。以下动作在定稿后必做，成本几十秒。

### 3.1 4×4 拼接（不是 2×2）

- 把定稿复制成 **4×4 网格**。2×2 只能看到一道接缝和一个角，四角交汇的"十字"看不出。
- 两级查看：**100%** 看接缝错位；**缩到 25%** 看密度河流（成条的空白带）。缩略状态下最容易暴露问题。

### 3.2 四角单独看

边能对上，角仍可能出错——四个角同时承担四条边。单独放大四角，看交汇处有没有多出一道十字线、有没有缺块。

### 3.3 灰度测试

转灰度再看。颜色会掩盖明暗不均：某一象限明显偏暗或偏密，铺开后就是斜条带，肉眼当时看不出来。

### 3.4 眯眼测试

眯眼或缩略，**最先跳出来的那个重复特征就是破绽**。通常是一个过大的主体，或几处等距排列。

### 3.5 三种接缝成因（对号入座）

| 现象 | 成因 | 修法 |
|---|---|---|
| 细白线 | 纹样差一点没贴边，留了空线 | 让纹样越过边界，交给模型补对侧；不要"刚好停在线内" |
| 每道接缝一条明暗带 | 单侧渐变、单侧偏亮 | 去掉全局渐变，地色拉平 |
| 等距网格、大花阵 | 单个主体过大，或间距过匀 | 改大小混合、加旋转、错开间距 |
| 接缝处半截断 | 未做接缝闭合 | 纹样要么完整穿过，要么对称断开 |

### 3.6 补救：斜向错接

等距感改不掉时，换错接方式：提示词写 `斜向错接排列` / `阶梯错接`，让相邻行错开半个单位。这对应印花的半错位（half-drop）、半砖（brick）排法，能消掉直网格——但会引入斜向节奏，改完必须重新做 4×4 检查。错位量的完整分档（0 / 1/2 / 1/3 / 2/5）见 `composition-basics.md` 1.5「错位量三档」。
