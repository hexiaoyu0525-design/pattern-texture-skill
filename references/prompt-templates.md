## 通用规则

所有出图提示词，建议遵循以下结构顺序：

```
[主体类型] + [风格/骨式] + [组织形式] + [配色方案] + [细节特征] + [质量词] + [背景/环境]
```

**顺序原则**：越核心的词放越前面，权重越高。

## 快速使用指南（分阶段）

### 阶段1：定方向（先想清楚再动手）

出图前先想清楚三件事，再选模板：

1. **出什么图？** → 单独纹样/四方连续/面料肌理/成衣效果/线稿 → 从下面5个场景模板里选最接近的
2. **什么风格？** → 宋式折枝/波普/极简几何/民族纹样... → 决定风格强度（见下方参数对照表）
3. **有没有参考图？** → 纯文生图 / 参考纹样 / 参考配色 / 参考工艺 → 决定参考图怎么分工（见下方参考图分工表）

> 不确定就先出1张定调小样，方向对了再深入。

### 阶段2：写提示词（按模板填内容）

1. 按模板填【主体类型】【风格/骨式】【组织形式】【配色方案】【细节特征】
2. 有参考图就按「参考图分工表」挂图1/图2/图3，并在提示词里点名每张图管什么
3. 四方连续必须加 `seamless pattern, tileable` 关键词；面料肌理必须加 `fabric close-up, macro shot`

### 阶段3：出图后自检（不对就改对应部分）

出图不对时，不建议整体重写，**只改对应部分**：

| 出图问题 | 改哪部分 |
|---|---|
| 纹样构成不对 | 改【骨式/组织形式】，或加图1锁纹样风格 |
| 配色不对 | 改【配色方案】，或加图2锁配色 |
| 工艺质感不对 | 改【材质/工艺描述】，或加图3锁面料质感 |
| 四方连续拼不上 | 加强 seamless/tileable 关键词，或出3×3拼接测试 |
| 风格太写实/太艺术 | 调风格强度参数（见下方参数对照表） |

## 参考图分工表

> 有参考图时按变量分工，**核心原则：一张图要有明确的参考优先级**——理想情况是一张图只锁一个变量（最可控），但实际使用中一张图经常天然带多个信息（比如一张成衣图既有服装又有纹样），这时候建议在提示词里说清楚：哪个主要参考、哪个次要参考、哪个不要参考。下面是0/1/2/3张的典型示例，不是强制顺序——具体哪张图管什么可以自己调整，只要在提示词里点名清楚就行。实际按平台支持的参考图数量类推。

| 参考图数量 | 适合场景 | 怎么分工 | 提示词怎么写 |
|---|---|---|---|
| **0张（纯文生图）** | 从零设计、灵感发散、快速预览 | 不用挂参考图 | 按模板完整写【主体类型】【风格】【骨式】【配色】 |
| **1张参考图** | 已有参考纹样，要改配色/改工艺 | 图1=纹样风格与骨式（锁整体感觉） | 提示词点名"图1是纹样风格，只换配色/只换工艺" |
| **2张参考图** | 已有纹样+已有配色方案 | 图1=纹样风格骨式；图2=配色色板 | 提示词点名"图1管纹样，图2管配色" |
| **3张参考图（典型）** | 精准复刻、多变量控制 | 图1=纹样风格；图2=配色；图3=面料/工艺质感 | 每张图只控制一个变量，建议不要一张图管所有 |
| **4张以上** | 超精细控制、多变量叠加 | 继续按"一图一变量"加：图4=应用部位参考、图5=成衣效果参考、图6=工艺细节参考… | 逐张点名各自管什么，避免图多了互相干扰 |

**参考图投喂原则**：
- 纹样参考图最好是清晰的平面图，建议不要带成衣（避免服装造型干扰）
- 配色参考图可以是面料色卡或色板
- 工艺参考图最好是微距特写（能看到织纹/光泽/凹凸）
- **参考图不是越多越好**：变量已经锁够了就停，多了反而互相打架

## 出图参数对照表

> 不同场景推荐的比例、风格强度、细节强度。风格强度对应 Midjourney `--s` 参数，即梦/Seedream 对应"风格强度"或"创意程度"滑块。

| 场景 | 推荐比例 | 风格强度（--s） | 细节强度 | 为什么 |
|---|---|---|---|---|
| **单独纹样（白底提取）** | 1:1 | 100-250（中） | 中高 | 要精致但不要太艺术，方便后期抠图 |
| **四方连续（满铺印花）** | 1:1 | 100-250（中） | 中高 | 强调无缝拼接，细节要均匀 |
| **面料肌理特写（微距）** | 1:1 或 4:3 | 50-100（低） | 极高（织纹细节） | 要真实纹理，不要美化，看得到织纹/光泽/凹凸 |
| **成衣应用效果** | 3:4（竖版） | 100-250（中） | 中等 | 重点看服装整体效果，纹样比例要对 |
| **线稿图（黑白）** | 1:1 | 0-50（极低） | 中等 | 要干净线条，不要艺术发挥 |

> 原则：数值越低越写实、越按提示词来；数值越高越艺术、越发挥。面料肌理/线稿用低值，单独纹样/成衣用中值。

## 三步出图标准流程

设计一个纹样时，建议按以下三步递进输出，而不是只出一张图：

| 步骤 | 产出 | 用途 | 对应场景 |
|---|---|---|---|
| **第一步：平面纹样图** | 1:1 矢量风格平面图 | 看构成、配色、布局对不对 | 场景二：四方连续 |
| **第二步：面料工艺图** | 面料肌理+工艺质感特写 | 看印染/刺绣/烫金落地后是什么感觉 | 场景三：面料肌理特写 |
| **第三步：成衣效果图** | 穿在衣服上的整体效果 | 给客户看最终成品是什么感觉 | 场景四：成衣应用效果 |

**为什么要三步**：
- 第一步解决"纹样本身对不对"的问题
- 第二步解决"工艺落地后是什么感觉"的问题
- 第三步解决"穿在身上最终效果"的问题

**注意**：三步不是必须的，根据需要选。如果只需要看纹样本身，出第一步就够了；如果要给客户看完整方案，三步都出。

## 五种出图场景模板

### 场景一：单独纹样（白底，方便提取）

**用途**：设计一个单独的装饰纹样，白底方便后期抠图用在衣服上。

**提示词模板**：
```
单独纹样设计，[风格标签]风格，[骨式]构图，[主体元素]，
[配色方案：主色+辅助色+点缀色]，
线条清晰，轮廓明确，[细节描述：如"缠枝藤蔓环绕花卉"]，
高质量纹样设计，矢量风格，干净简洁，
纯白背景，居中构图，纹样周围留适当留白
```

**负面提示词（建议加）**：
```
photorealistic, photo, realistic texture, 3d render,
cluttered background, multiple patterns, off-center,
blurry, low quality, distorted
```

**参数建议**：
- 比例：1:1
- 风格强度：中等（不要太艺术，要清晰）
- 细节强度：中高（纹样要精致）

---

### 场景二：四方连续（满铺，无缝拼接）

**用途**：生成满铺面料印花，要求无缝拼接。

**提示词模板**：
```
四方连续纹样图案，[风格标签]风格，[骨式]骨式，
[组织形式：如"散点式" / "连缀式" / "锦地开光式"]，
[主体元素：如"折枝花卉" / "几何几何" / "缠枝纹"]，
[配色方案]，
无缝拼接图案，tile pattern，repeat pattern，
满铺效果，纹样均匀分布，疏密有致，
平面印花风格，清晰轮廓，[复杂度：如"中等复杂度"]，
[去AI塑料感：如"细节有自然变化，手工感，非机器完美"]
```

**负面提示词（建议加）**：
```
seam visible, broken pattern, uneven distribution,
clustered, too dense, too sparse,
photorealistic, 3d, shading, depth,
blurry, low quality
```

**参数建议**：
- 比例：1:1（方便看拼接效果）
- 风格强度：中等
- 细节强度：中高

**关键约束**：
- 必须强调 "seamless tile pattern"、"repeat pattern"
- 建议避免明显边界感
- 建议避免太大空白或太密集区域

---

### 场景三：面料肌理特写（材质感，微距）

**用途**：生成面料肌理的特写图，看材质效果。

**提示词模板**：
```
[肌理类型，如"提花面料" / "绗缝肌理" / "扎染棉布"]面料特写，
微距镜头，面料纹理细节，[材质特征：如"有凹凸感" / "光泽感" / "透孔感"]，
[颜色：如"深藏蓝色" / "米白色"]，
真实面料质感，自然纹理，
[去AI塑料感：如"手工感，自然随机，非完美均匀"]，
8K高清细节，微距摄影，面料平铺
```

**负面提示词（建议加）**：
```
printed pattern, graphic design, flat illustration,
digital art, plastic texture, artificial,
perfectly uniform, synthetic, fake fabric,
blurry, low quality
```

**参数建议**：
- 比例：1:1 或 4:3
- 风格强度：低（要真实，不要太艺术）
- 细节强度：极高（肌理要清晰）

**关键约束**：
- 必须强调 "fabric texture"、"macro shot"、"realistic fabric"
- 不能有"图案感"，要是"材质感"
- 要区分开：这是面料本身的肌理，不是印上去的图案

---

### 场景四：成衣应用效果（穿在身上/衣服上）

**用途**：看纹样穿在衣服上的整体效果。

**提示词模板**：
```
[服装类型，如"连衣裙" / "西装外套" / "围巾"]，
[风格标签]风格，[纹样类型：如"满身印花" / "局部点缀" / "边饰"]，
[纹样描述：如"宋式折枝花卉四方连续"]，
[配色方案]，
模特穿着效果，[模特描述：如"简约模特，自然站姿"]，
服装正面展示，全身/半身，
[背景：如"纯色背景" / "极简摄影棚"]，
时尚摄影质感，高质量服装展示，
面料垂坠感自然，纹样清晰可见
```

**负面提示词（建议加）**：
```
model face focus, close up face, portrait only,
distorted clothing, weird proportions,
cluttered background, busy scene,
low quality, blurry, watermark
```

**参数建议**：
- 比例：3:4（竖版，适合展示全身）
- 风格强度：中等
- 细节强度：中等（重点看服装，不是看脸）

**关键约束**：
- 重点是服装，不是模特脸
- 纹样要清晰可见，建议避免被阴影吃掉
- 面料垂坠感要自然

---

### 场景五：线稿图（黑白线描，方便画草图）

**用途**：生成黑白线稿，方便学生画草图或做工艺底稿。分两种情形：从零生成线稿，或把已有的彩色成品重绘成线稿。

**情形 A：从零生成线稿（提示词模板）**
```
黑白线描纹样，[风格标签]风格，[骨式]构图，
[主体元素]，
干净的线条，清晰轮廓，
[细节：如"内部有结构线" / "有疏密变化"]，
线稿插画，white background, black line art,
矢量风格，线条流畅，
[复杂度：如"中等复杂度，有细节但不杂乱"]
```

**情形 B：从彩色成品重绘线稿（建议分两遍，不要指望一次到位）**

当线稿要和某张彩色成品严格对应，或线稿老是发灰发淡时，按两遍走：

- 第一遍（对齐结构）：以彩色成品为唯一结构基准，在提示词里逐项点明要对应的元素（中心主纹、四周每个小团纹各是什么、地纹网格、角花、外框、最外白框），要求位置、大小、数量一一对应、不增不减，先保证结构对齐。
- 第二遍（两值锐化）：以第一遍结果为基准、只改清晰度，显式声明只用纯黑与纯白两个值：`two-tone pure black and white, only solid black lines on pure white background, no grayscale, no light gray, no semi-transparent, no blurry lines`；保留粗/中/细三层粗细分工——主纹轮廓粗线、团珠网格云纹中线、最密地纹细线，但细线也必须是纯黑实线。

> 实测要点：只写"线条清晰、纯黑、无灰阶"，模型仍容易输出整体偏灰、细线过淡的线稿；显式写出"two-tone pure black and white"才稳定得到实心黑线。

**负面提示词（建议加）**：
```
color, shading, grayscale, painted,
photorealistic, 3d, texture,
blurry, thick lines, messy,
colored pencil, watercolor,
light gray, faint lines, washed out
```

**参数建议**：
- 比例：1:1（从彩色成品重绘时沿用原图比例）
- 风格强度：低
- 细节强度：中等

## 负面提示词库（带风格前提）

> **重要**：负面提示词不是所有场景都必加，要根据你想要的风格调整。下面标注了哪些是"所有场景都加"，哪些是"默认加，但某些风格可以去掉"。

### 基础负面提示词（所有场景建议加）
```
low quality, blurry, distorted, watermark, text, signature,
ugly, unattractive, poorly designed
```

### 纹样专用负面提示词（默认加，部分可按风格去掉）
```
generic pattern, boring design, cliché,
flat, lifeless, no depth
```
- `overly detailed, cluttered, messy composition` → **默认加，但满密繁复风格（云锦/巴洛克/伊斯兰纹样）可以去掉**
- `digital art, illustration style` → 想要真实感时加，想要插画风格时不加

### 去AI塑料感专用负面提示词（默认加，精确几何风格可去掉）
```
plastic texture, synthetic, artificial,
digital painting smoothness, CGI look,
generic AI pattern, cookie cutter design
```
- `overly smooth, too clean, machine-perfect` → **默认加，但精确几何风格（包豪斯/波普/工业风）可以去掉**

**关键原则**：去AI味 = 细节的手工感，不是破坏整体构成。
- ✅ 正确做法：花瓣形状有轻微差异、线条有自然不均匀、颜色有细微深浅变化
- ❌ 错误做法：整体对称被打破、重复单元大小不一、构图歪斜（这会把纹样本身搞坏）

**注意**：纹样本身就是靠规整构成的（四方连续要重复、团花要对称、二方连续要均匀），这些**建议不放进负面提示词**。去AI味是体现在**细节的手工感**上，不是破坏整体构成。

### 面料肌理专用负面提示词
```
printed pattern, graphic, flat design,
fake fabric, artificial texture,
3d render, cgi, plastic
```
- `too uniform, synthetic looking` → **默认加，但想要均匀平整的面料（比如缎面）可以去掉**

## 提示词权重控制

### 核心词（建议放最前面，权重最高）
- 主体类型（单独纹样/四方连续/面料肌理/成衣）
- 风格标签（宋式折枝/波普/极简几何...）
- 组织形式（二方连续/四方连续/散点式...）

### 修饰词（放中间，权重中等）
- 配色方案
- 骨式描述
- 细节特征

### 质量词（放最后，权重最低但建议有）
- 高质量、8K、精细、专业设计

### 去AI塑料感关键词（放最后但建议加）
- 手工感、自然随机、非机器完美、手工痕迹

**权重原则**：
- 核心词占提示词前 30%
- 修饰词占中间 50%
- 质量词和去AI味词占最后 20%
- 建议不要把所有词都堆在一起，要有层次

## 常见问题FAQ（出图踩坑解决方案）

### Q1：四方连续拼接不上，有明显接缝

**原因**：AI模型要同时满足"无缝拼接"和"美学效果"两个目标，经常顾此失彼。

**解决方案**：
1. **提示词里必须加的关键词**：
   - `seamless pattern` / `无缝拼接`
   - `tileable` / `可平铺`
   - `repeating pattern` / `重复纹样`
   - `all-over pattern` / `满版纹样`
2. **加"随机分布"**：
   - `scattered elements, random placement, no grid`
   - 避免元素排成整齐的行列
3. **后处理修缝**：
   - 生成后用Photoshop的"位移"滤镜，检查接缝
   - 用仿制图章工具修掉明显的接缝
4. **检查方法**：
   - 把生成的图排成 3×3 网格
   - 缩小看整体效果，放大看接缝处
   - 沿拼接线找线条、空隙、截断形状

---

### Q2：去AI味总是做不好，还是像AI生成的

**原因**：去AI味的方向搞错了——不是破坏整体构成，而是细节要有手工感。

**解决方案**：
1. **正确的去AI味方向**：
   - ✅ 细节有自然变化：`slight variations in size, shape, and color`
   - ✅ 手工感：`hand-drawn feel, organic imperfections`
   - ✅ 随机感：`natural randomness, not machine-perfect`
2. **错误的去AI味方向（不建议用）**：
   - ❌ 建议不要说"非对称"、"不规整"——纹样本身就是要规整的
   - ❌ 建议不要说"混乱"、"随意"——会把纹样搞乱
3. **关键认知**：
   - 去AI味 = 细节的手工感，不是破坏整体构成
   - 纹样的整体构成（重复、对称、均匀）是对的，细节要有自然变化

### Q3：烫金/金属效果总是出不来，就是普通金色

**原因**：普通"金色"只是颜色，不是金属质感。

**解决方案**：
1. **明确说金属质感**：
   - `metallic gold foil, hot stamping`（烫金箔）
   - `shiny metallic finish, reflective surface`（闪亮金属质感）
2. **加光线描述**：
   - `catches light, shimmering`（反光、闪烁）
3. **区分不同金色**：
   - 烫金 = 平面金属光泽
   - 刺绣盘金 = 凸起的金线
   - 织金 = 织进面料里的金属线

### Q4：面料肌理总是出不来，还是像平面图案

**原因**：提示词里只说了图案，没说面料。

**解决方案**：
1. **明确说"面料特写"**：
   - `fabric close-up, macro shot`（面料特写，微距）
   - 不要只说"pattern"，要说"fabric pattern"
2. **加面料类型**：
   - `cotton linen blend texture`（棉麻混纺纹理）
   - `silk satin weave`（真丝缎面）
3. **加质感描述**：
   - `visible weave, fabric texture`（能看到织物纹理）
   - `natural fabric drape`（面料垂坠感）
