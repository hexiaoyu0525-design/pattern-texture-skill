# 纹样分析工作流

拿到一张纹样参考图，按这个流程一步步拆解，输出完整的分析报告。

## 目录

- 分析总流程
- 第一步：类型判断
- 第二步：组织形式识别
- 第三步：骨格结构拆解
- 第四步：配色体系分析
- 第五步：工艺适配判断
- 第六步：风格标签定位
- 第七步：可转译性评估
- 输出模板

## 分析总流程

```
拿到参考图
    ↓
第一步：判断是平面图案还是结构肌理
    ↓
第二步：判断组织形式（单独/适合/二方连续/四方连续）
    ↓
第三步：拆解骨格结构（对称/均衡/发射/渐变...）
    ↓
第四步：分析配色体系（主色/辅助色/点缀色、调性）
    ↓

    ↓
第六步：定位风格标签（属于什么风格体系）
    ↓
第七步：评估可转译性（能不能用、怎么转、注意什么）
```

## 第一步：类型判断

先区分这张图是**平面图案**还是**结构肌理**，还是两者混合。

| 判断维度 | 平面图案 | 结构肌理 |
|---|---|---|
| 有没有明确的图形轮廓 | 有 | 没有（是纹理） |
| 是"画"上去的还是面料本身的 | 画/印/绣上去的 | 面料本身的凹凸/光泽 |
| 能不能单独抠出来用 | 能 | 不能（就是面料本身） |

**输出**：明确标注"平面图案为主" / "结构肌理为主" / "混合类（X为主，Y为辅）"

---

## 第二步：组织形式识别

判断这个纹样属于哪种组织形式：

| 类型 | 判断特征 |
|---|---|
| **单独纹样** | 独立存在，不连续延伸，单个图案 |
| **适合纹样** | 适应特定外形（圆形团花、方形装饰、角花） |
| **二方连续** | 沿一个方向带状重复，像花边 |
| **四方连续** | 上下左右都能重复，满铺面料效果 |
| **边缘纹样** | 专门在边缘，单边/双边/围合 |
| **地纹+浮纹** | 底纹+主纹两层结构，锦地开光式 |

**判断技巧**：
- 看能不能无限延伸？能 → 连续纹样
- 看有没有轮廓限制？有 → 适合纹样
- 看是满铺还是局部？满铺 → 四方连续；局部 → 单独/适合

---

## 第三步：骨格结构拆解

这是最核心的一步，拆解纹样的骨架逻辑。

### 对称类
- **绝对对称**：左右/上下完全镜像
- **相对对称**：大体对称，细节有变化
- **旋转对称**：绕中心旋转一定角度重合
- **放射对称**：从中心向外放射状

### 均衡类
- **不对称均衡**：左右不对称，但视觉重量平衡
- **散点均衡**：大小单元散点分布，疏密有致

### 发射类
- **离心发射**：从中心向外扩散
- **向心发射**：从四周向中心汇聚
- **同心圆环**：一层层同心圆

### 重叠类
- **透叠**：半透明叠加
- **覆叠**：前后遮挡
- **锦地开光**：底纹+主纹两层结构

**拆解方法**：
1. 先找最明显的骨架线（对称轴/中心点/重复单元）
2. 再看元素怎么排布（对称/散点/连缀）
3. 最后看层次（几层叠加、谁在前谁在后）

---

## 第四步：配色体系分析

### 色彩提取
- **主色**：面积最大的颜色（约占60-70%）
- **辅助色**：第二大面积（约占20-30%）
- **点缀色**：最小面积，提亮用（约占5-10%）

### 调性判断
| 维度 | 判断 |
|---|---|
| 纯度 | 高饱和 / 中饱和 / 低饱和（灰调） |
| 明度 | 高明度（浅）/ 中明度 / 低明度（深） |
| 冷暖 | 暖调 / 冷调 / 冷暖对比 |
| 对比 | 强对比 / 中对比 / 弱对比 |

### 配色方法判断
- 同类色调和（同一色相不同深浅）
- 邻近色调和（色环相邻）
- 对比色调和（色环距离远，用中性色过渡）
- 无彩色调和（黑白灰+一个点缀色）

**判断技巧**：去掉颜色只看黑白灰，如果构成依然成立，说明结构好；如果去掉颜色就乱了，说明是配色在撑场面。

---

## 第五步：工艺适配判断

### 原生工艺判断
这个纹样原本是用什么工艺做的？

| 工艺类型 | 判断特征 |
|---|---|
| **数码印花** | 精细渐变、复杂色彩、照片级效果 |
| **丝网印** | 有限套色、大色块、边缘清晰 |
| **刺绣** | 有凹凸感、线迹感、绣线质感 |
| **提花织造** | 有织物肌理感、纹样是织出来的 |
| **蜡染/扎染** | 晕染边缘、随机裂纹、不均匀 |
| **手绘** | 笔触痕迹、自由随性 |

### 转译工艺判断
如果要换一种工艺实现，适合换什么？不适合换什么？
- 适合：XXX工艺，因为...
- 不适合：XXX工艺，因为...

---

## 第六步：风格标签定位

这个纹样属于什么风格体系？

从四个族里选：
- **东方传统**：中国历代/民族/日本/南亚中亚
- **西方历史**：古典/中世纪/巴洛克/洛可可/Art Deco
- **现代当代**：波普/欧普/极简/街头/复古
- **其他地区**：非洲/美洲/大洋洲/东南亚

**输出**：给2-3个风格标签，比如"宋代折枝 + 低饱和莫兰迪 + 东方雅致"

---

## 第七步：可转译性评估

### 可提取的核心要素
- 骨格结构（可以直接提取用）
- 配色体系（可以直接套用）
- 构图逻辑（可以参考）
- 元素特征（可以简化/重构）

### 转译建议
- **直接用**：什么情况下可以直接借鉴
- **简化用**：怎么简化细节
- **解构用**：怎么打碎重组
- **风险提示**：有没有版权问题、有没有工艺限制
